# ✅ 검증 체크리스트 (2중 검증 시스템)

## 🚨 모든 "완료" 선언 전 필수 확인

### Level 1: 체크리스트 검증 (파일별 거짓 확인)

**완료 기준**:
```
✅ 모든 수정된 파일 목록 작성
✅ 각 파일에 대해:
   - 어떤 거짓을 수정했는가?
   - 어떤 증거/파일로 확인했는가?
   - 혹시 더 남은 거짓이 있는가?
✅ 코드/스크립트/주석의 거짓도 확인
✅ 메모리에 이 체크리스트 기록
```

---

### Level 2: 2중 검증 (재확인)

**첫 번째 검증 후 30분 이상 경과 후**:
```
✅ 파일 다시 읽기 (검증 1차)
✅ 혹시 놓친 거짓 찾기 (검증 2차)
✅ 다시 커밋해야 하는 것 있는가? (검증 3차)
✅ 결과를 메모리에 기록
```

---

### Level 3: 메모리 기록 의무

**기록 항목**:
```
검증 날짜/시간
점검한 파일들
발견된 거짓들
재검증 결과
최종 상태 (✅ 완료 또는 ❌ 불완전)
```

---

## 🔴 "완료했습니다"라고 말할 수 없는 경우

❌ 체크리스트 없음
❌ 메모리 기록 없음
❌ 2중 검증 안 함
❌ 검증 시간이 너무 짧음 (<30분)
❌ 코드/스크립트/주석 미확인
❌ 실행 증거 없음 (로그, 바이너리, 테스트 결과)
