## 완성된 4개 포스트

### 1️⃣ Post 1: V3 컴파일러 파이프라인
- **파일**: `post-1-compiler-pipeline.md` (5.4KB, ~2,000단어)
- **대상**: 언어 설계 관심층, 개발 리드
- **주요 내용**:
  - Lexer (30개 토큰)
  - Pratt Parser (우선순위)
  - Type System (검증)
  - Code Generation (Go/바이트코드)
  - 성능: 5,000줄 45ms
- **포맷**: Brand Voice 준수, 초보자-전문가 수준별 설명

### 2️⃣ Post 2: 모듈 시스템
- **파일**: `post-2-module-system.md` (6.2KB, ~2,100단어)
- **대상**: 팀 리드, 아키텍처 설계자
- **주요 내용**:
  - 파일 = 모듈 개념
  - pub 키워드로 공개 API 명시
  - 중첩 모듈 (utils.string 등)
  - 순환 의존성 자동 감지
  - 패키지 시스템 (재사용)
- **예제**: 이메일 검증 모듈 실전 예제

### 3️⃣ Post 3: 비동기 프로그래밍
- **파일**: `post-3-async-programming.md` (7.8KB, ~2,200단어)
- **대상**: 백엔드 개발자, 성능 최적화 관심층
- **주요 내용**:
  - I/O 대기 문제
  - Callback → Promise → Async/Await 진화
  - 병렬 처리 (5배 성능 개선)
  - 에러 처리
  - 실제 성능 벤치마크
- **실적**: 동기 500ms → 비동기 100ms

### 4️⃣ Post 4: REST API 설계
- **파일**: `post-4-rest-api-design.md` (8.3KB, ~2,300단어)
- **대상**: API 설계자, 신입 개발자
- **주요 내용**:
  - REST 원칙 (GET/POST/PUT/DELETE)
  - URL 구조 (명확성)
  - HTTP 상태 코드 (일관성)
  - 응답 형식 표준화
  - 페이징, 필터링, 정렬
  - 인증 & 권한
  - 성능: 50K req/sec
- **체크리스트**: 9개 항목으로 API 품질 검증
