### Phase H 구현 계획

**1. 기본 E2E 테스트 (실제 작동)**
   - `test_e2e_hello_world()` - 완벽한 파이프라인
   - `test_e2e_simple_arithmetic()` - 변수, 산술 연산
   - `test_e2e_function_call()` - 함수 정의 및 호출

**2. 고급 테스트**
   - 배열, 딕셔너리, 집합 처리
   - 제어 흐름 (if/else, for, while)
   - 패턴 매칭, 구조체

**3. 성능 & 신뢰성 테스트**
   - 대규모 프로그램 (피보나치, 팩토리얼)
   - 메모리 누수 감지
   - 벤치마크 (컴파일 속도, 바이너리 크기)

**4. 에러 처리 테스트**
   - 타입 에러 감지
   - 정의되지 않은 변수
   - 구문 오류 복구

### 구현 우선순위
1. **P0**: `test_e2e_hello_world()` - 핵심 검증
2. **P1**: 기본 산술, 함수 호출 - 기본 기능
3. **P2**: 고급 기능 (배열, 딕셔너리) - 확장성
4. **P3**: 성능 최적화 - 프로덕션 준비
