# 🔷 kim의 작업 철학

## 핵심 원칙

### ❌ 중요하지 않은 것
- 파일이 어디에 있는가?
- 코드가 완벽한가?
- 현재 의미 있는가?
- 검증되었는가?

### ✅ 가장 중요한 것
- **진행하고 있는가? (Momentum)**
- **성장하고 있는가? (Growth)**
- **멈추지 않는가? (Never Stop)**

---

## 실행 원칙

```
"24시간이면 10만줄 생산한다.
이게 맞는지 실험인지 중요하지 않다.
난 지시하고 실행한다.
너가 볼때 의미 없는것일지라도."
```

**→ 속도와 반복이 완벽함을 이긴다**

---

## 협업 스타일

- 🎯 **지시 → 실행** (설명하지 말고 하라)
- ⚡ **빠른 반복** (완벽하지 않아도 진행)
- 🔄 **지속적 진화** (Phase 단위 성장)
- 📊 **결과 중심** (코드 라인 수, 테스트 통과, 배포)
