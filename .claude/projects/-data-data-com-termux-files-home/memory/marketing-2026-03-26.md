## 📝 작성한 포스트 상세 내용

### 1. V3 언어 컴파일러 파이프라인 (560줄)

**구성:**
- 배경: 프로그래밍 언어 이해
- 문제: 텍스트 → 실행 파일 변환
- 해결책: 4단계 파이프라인

**기술 깊이:**
- Lexer: 토큰화 (TypeScript 코드)
- Parser: AST 생성 (인터페이스 정의)
- Compiler: 바이트코드 (PUSH, STORE, LOAD)
- Runtime: 스택 기반 실행 (AIVM)

**대상 독자:** 초보→전문가

---

### 2. FreeLang 모듈 시스템 (573줄)

**구성:**
- 배경: 왜 모듈이 필요한가?
- 문제: 거대한 단일 파일의 한계
- 해결책: 모듈 시스템 (import/export)

**예제 진행:**
1. 기본 구조 (salary.fl, main.fl)
2. 초보자: 계산기 (4개 모듈)
3. 전문가: 은행 시스템 (6개 모듈, 의존성)

**고급 기능:** 네임스페이스, 부분공개, 재export

---

### 3. 비동기 프로그래밍 (555줄)

**구성:**
- 배경: 왜 비동기가 필요한가?
- 문제: 동기 코드의 대기 시간
- 해결책: async/await

**진행 구조:**
1. 기본: 타이머 (wait_seconds)
2. 병렬 실행: 2초 → 3초 최소화
3. 전문가: 웹 크롤러 (1000개 페이지 4배 가속)

**패턴:** Error handling, Timeout, Race, Promise.all

---

### 4. REST API 설계 (693줄)

**구성:**
- 배경: API의 중요성
- 문제: 나쁜 API 설계
- 해결책: RESTful 원칙

**상세 구현:**
1. 인증: Register/Login/JWT
2. 계좌: CRUD + 조회
3. 거래: Deposit/Withdraw/Transfer
4. 에러 처리: 400/401/402/404
5. 성능: 캐싱, 압축, 배치

**고급:** 페이지네이션, 필터링, 트랜잭션 무결성
