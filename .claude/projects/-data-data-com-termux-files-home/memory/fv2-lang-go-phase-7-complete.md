## 🐛 발견 및 수정된 4개 버그

### Bug #1: Pattern 타입 오류 (D+ 원인)
```
문제: arm.Pattern.Value (인터페이스에 없는 필드)
해결: 타입 어서션으로 LiteralPattern, IdentifierPattern, WildcardPattern 처리
결과: ✅ 코드 생성 정상화
```

### Bug #2: 배열 크기 계산
```
문제: 변수 배열에서 sizeof 불가능
해결: 컴파일타임 리터럴 vs 런타임 변수 구분
결과: ✅ for-in 루프 안정화
```

### Bug #3: 타입 추론
```
문제: 명시적 타입 없으면 "auto" (C99 미지원)
해결: inferTypeFromExpression() 함수로 타입 추론
결과: ✅ long long, double, char* 등 명확한 타입
```

### Bug #4: Main 함수 중복 (B+ 달성 후)
```
문제: FV main → void main(void) forward declaration + int main() 자동 생성
      → 중복된 main 함수로 C 컴파일 오류
해결: main 함수는 forward declaration 제외, C의 int main()으로 직접 사용
결과: ✅ 올바른 C 코드 생성, gcc/clang 컴파일 성공
```

3. **실행 우선 (작섭시삭)**

   - 생성된 C 코드가 gcc 컴파일 불가능
