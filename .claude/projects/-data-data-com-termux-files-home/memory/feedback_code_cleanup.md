---
name: 코드 정리 시 제거 vs 주석 처리
description: 코드 정리할 때 함수/코드 제거보다 주석 처리를 우선 검토해야 한다는 피드백
type: feedback
---

제거보다 주석 처리가 실수 방지에 낫다.

**Why:** 함수나 코드를 완전 제거하면 나중에 비슷한 역할이 다시 필요할 때 처음부터 작성해야 하고, 제거 의도가 기록에 남지 않는다. 주석 처리하면 "이 코드가 있었고 왜 쓰지 않는지"가 명확히 남는다.

**How to apply:**
- 코드 정리(refactor) 시 함수를 "대체"했다면 → 대체된 함수를 주석으로 남기고 // replaced by: XXX 명시
- 단순히 "현재 미사용"이라서 제거하려면 → 주석 처리 후 이유 기록
- 완전 제거가 맞는 경우: 동일 기능이 다른 이름으로 존재하고, 혼란만 가중될 때
- 의심스러우면 제거 대신 주석 처리를 선택
