**규칙 1️⃣: 체크리스트 검증 (Checklist Verification)**
```
"완료했습니다"라고 말하기 전에, 반드시:

✅ 모든 수정된 파일 목록 작성
✅ 각 파일에 대해:
   - 어떤 거짓을 수정했는가?
   - 어떤 증거/파일로 확인했는가?
   - 혹시 더 남은 거짓이 있는가?
✅ 코드/스크립트/주석의 거짓도 확인
✅ 메모리에 이 체크리스트 기록
```

**규칙 2️⃣: 2중 검증 (Double Verification)**
```
첫 번째 검증 후 1시간 뒤:
✅ 파일 다시 읽기 (검증 1)
✅ 혹시 놓친 거짓 찾기 (검증 2)
✅ 다시 커밋해야 하는 것 있는가? (검증 3)
✅ 결과를 메모리에 기록
```

**규칙 3️⃣: 메모리 의무 기록**
```
모든 검증 결과를 이 파일에 기록:
- 검증 날짜/시간
- 점검한 파일들
- 발견된 거짓들
- 재검증 결과
- 최종 상태 (✅ 완료 또는 ❌ 불완전)

이 기록이 없으면 "완료"를 선언할 수 없음
```
