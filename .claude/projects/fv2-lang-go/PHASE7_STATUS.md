### Task #1: Match 문 패턴 조건 생성
**상태**: 🟠 In Progress
**문제**:
- Match 문이 파서에서 올바르게 파싱되지만
- Generator에서 generateMatchStatement() 호출 안 됨
- 패턴 타입이 인터페이스로 변경됨

**개선 내용**:
```go
// 이전: arm.Pattern.Value 직접 접근 (불가능)
// 수정: Pattern 인터페이스 타입 어서션 추가

switch p := arm.Pattern.(type) {
case *ast.LiteralPattern:
    // 리터럴 패턴 처리
case *ast.IdentifierPattern:
    // 식별자 패턴 처리
case *ast.WildcardPattern:
    // 와일드카드 처리
}
```

**기대 효과**:
- Match 문 올바른 코드 생성
- 패턴 매칭 완벽 구현

### Task #2: 배열 크기 계산 (for-in 루프)
**상태**: 🟠 In Progress
**문제**:
- for-in 루프에서 배열 크기 동적 계산 필요
- sizeof(arr)/sizeof(arr[0]) 패턴은 C 변수에서 작동 안 함
- 런타임 크기 정보 필요

**개선 방안**:
```go
// 배열 메타데이터 추적
type ArrayInfo struct {
    name string
    size int64  // 런타임 계산
}

// for-in 루프 생성 개선
for (size_t _i = 0; _i < array_len; _i++) {
    // 배열 요소 처리
}
```

**기대 효과**:
- 동적 배열 처리 정상화
- 배열 반복문 안정성 향상
