# FreeLang Content Policy (콘텐츠 정책)

모든 마케팅 팀 멤버가 준수해야 할 콘텐츠 작성 및 발행 정책입니다.

## 금지 콘텐츠

### 1. 거짓된 정보
❌ **금지**: 검증되지 않은 성능 수치 주장
```
❌ "FreeLang은 Python보다 1000배 빠르다"
✅ "우리 테스트에서 메모리 사용량 40% 감소 확인"
```

❌ **금지**: 경쟁 언어 비방
```
❌ "Go는 구식 언어다"
✅ "우리의 접근 방식은 다음과 같다..."
```

❌ **금지**: 미검증 사례 인용
```
❌ "한 회사가 사용해서 엄청 효율적이래"
✅ "[회사명] 케이스 스터디: ..." (동의 확인 후)
```

### 2. 스팸성 홍보
❌ **금지**: 무관한 댓글에 강제로 FreeLang 언급
```
❌ "Python 관련 스레드에 무조건 FreeLang 추천"
✅ "특정 문제 해결에 FreeLang이 도움 될 수 있습니다"
```

❌ **금지**: 자동 생성된 댓글
- 같은 문구 반복 (패턴 감지 시 삭제)
- 문맥 무시한 링크 배포
- 봇 스타일 신속성 (사람처럼 생각하는 시간 필요)

❌ **금지**: 저작권 침해
```
❌ 다른 블로그 글 전문 복사
✅ 핵심 요약 + 출처 명시 + 자체 분석 추가
```

### 3. 기술적 부정직
❌ **금지**: 실행되지 않는 코드 예시
- 테스트 없이 공개 금지
- 동작 검증 후에만 발행

❌ **금지**: 벤치마크 조작
- Fair comparison 필수 (같은 조건, 같은 환경)
- 자체 최적화만 반영 금지

❌ **금지**: 생략된 한계
```
❌ "메모리 관리가 완벽하다"
✅ "메모리 관리: 장점 (...), 현재 한계 (...), 개선 로드맵 (...)"
```

### 4. 개인정보 & 보안
❌ **금지**: 공개된 내부 정보
- API 키, 토큰, 개인 이메일
- 직원 신원 노출 (동의 없이)
- 고객 사례 상세 공개 (NDA 위반)

❌ **금지**: 보안 취약점 공개
- 책임감 있는 disclosure 필수 (30일 공개 전 대기)

## 검증 규칙

### 발행 전 체크리스트

| 항목 | 확인 | 방법 |
|------|------|------|
| 사실 검증 | ✓ | 근거 링크 최소 1개 이상 |
| 코드 동작 | ✓ | 실제 실행 & 출력 확인 |
| 경쟁사 존중 | ✓ | 비교 시 공정한 설명 |
| 출처 명시 | ✓ | 인용은 항상 출처 표기 |
| 개인정보 제외 | ✓ | API 키/토큰/이메일 검색 |
| 톤 검증 | ✓ | brand-voice.md 규칙 확인 |
| 링크 유효성 | ✓ | 모든 링크 클릭 확인 |

### 에이전트별 검증 책임

**Content Writer**:
- 코드 예시 실행 (반드시 2 이상 환경에서 테스트)
- 수치 출처 기록
- 관련 글 중복 확인

**Social Media Manager**:
- 링크 유효성 확인 (404 방지)
- 140자 이하 요약 정확성
- 이모지 3개 제한 준수

**Community Manager**:
- 스레드 전체 읽기 (문맥 파악)
- 기존 댓글 중복 확인
- 홍보성 제거 (진정성 유지)

**Analytics**:
- 수치 소수점 재확인
- 비교 기준 명시 (어제 vs 목표 vs 지난주)
- 추세 분석 신뢰도 표시

## 위반 대응

### Level 1: 경고 (교정 가능)
- 코드 미테스트, 소수점 오류, 링크 404
- **조치**: 에이전트에게 재수정 지시, 발행 연기

### Level 2: 중단 (부분 위반)
- 검증 생략, 출처 미표기, 경쟁사 부정확 표현
- **조치**: 해당 콘텐츠 발행 거부, 이유 명시, 수정 후 재검토

### Level 3: 정지 (심각한 위반)
- 허위 정보, 저작권 침해, 개인정보 노출
- **조치**: 콘텐츠 삭제, CMO 보고, 2주 활동 중단, 교육 재이수

## FAQ

**Q: 벤치마크 수치는 언제 공개 가능한가?**
A: 다음 3개 조건 모두 만족 시:
1. 테스트 코드 공개 (재현 가능)
2. 하드웨어/환경 명시
3. 공정한 비교 (같은 최적화 수준)

**Q: 경쟁 언어 언급은 절대 금지인가?**
A: 아니오. 다음 형식 추천:
- "A 언어는 X에 강하고, 우리는 Y를 강조합니다"
- "비슷한 문제? 우리는 이렇게 해결했습니다"
- 비방이 아닌 비교

**Q: 고객 사례 공유하고 싶은데?**
A: 3단계 프로세스:
1. 고객 동의서 확보
2. 민감 정보 제거
3. CMO 검토 후 발행

---

**핵심**: "거짓이 아닌 것"이 아니라 "검증된 진실"을 발행하세요.
