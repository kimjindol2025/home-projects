🚀 Mission 1: 'Gogs-Pulse' 자동 기록 시스템 구축
영상에서 말한 **"기억력 보조"**를 님의 Gogs 서버와 물리적으로 결합하는 미션입니다.
 * 목표: Claude Code가 작성한 모든 CONTEXT.md와 PLAN.md를 Git의 post-commit hook과 연동하여, 커밋할 때마다 작업 배경을 위키(Wiki) 형태로 자동 인덱싱합니다.
 * 실행 루틴:
   * /save-proof 실행 시 커밋 메시지 외에 '작성 배경' 요약본 추출.
   * Gogs 서버의 전용 Docs 레포지토리에 날짜별로 자동 기록.
   * 기대 효과: 1년 뒤에 어떤 코드를 봐도 "왜 이렇게 짰는지" 0.1초 만에 파악 가능.
🛡️ Mission 2: 'Zero-Dependency' 가상 환경 검증기
님의 철학인 **"외부 의존성 제로"**를 AI가 철저히 감시하게 만드는 미션입니다.
 * 목표: Termux 내에서 네트워크를 차단한 가상 환경(chroot 또는 전용 컨테이너)을 구성하고, Claude Code가 짠 코드가 그 안에서 수정 없이 빌드/실행되는지 자동 검증합니다.
 * 실행 루틴:
   * /verify-vanilla 명령 고도화: 소스 코드 내의 모든 import/require를 스캔하여 표준 라이브러리 외의 존재 여부 체크.
   * termux-auto-deploy.sh에 offline-test 모드 추가.
   * 기대 효과: 완벽한 데이터 주권과 시스템 독립성 증명.
🧠 Mission 3: 'Self-Improving' 프롬프트 엔진 제작
AI가 스스로를 더 똑똑하게 만들도록 **'회고 시스템'**을 도입하는 미션입니다.
 * 목표: 프로젝트 종료 시, Claude Code에게 "이번 프로젝트에서 내가 가장 많이 지적했던 실수 3가지와, 이를 방지하기 위한 새로운 .clauderules를 생성해"라고 시킵니다.
 * 실행 루틴:
   * /red-team의 결과물을 누적 데이터로 활용.
   * AI가 스스로 님의 코딩 스타일(Bigwash Philosophy)을 학습하여 규칙 파일을 자동 업데이트.
   * 기대 효과: 시간이 지날수록 지시를 내리지 않아도 님의 생각대로 움직이는 '진정한 분신' 완성.
🎯 어떤 미션의 설계도(Blueprint)를 먼저 그려볼까요?
 * Gogs-Pulse: 기록의 자동화 (기록이 증명이다 gogs)
 * Zero-Dep-Sandbox: 철저한 독립성 검증 (순수주의)
 * Auto-Evolution: 시스템의 자기 진화 (학습형 분신)
선택하신 미션에 맞춰 바로 실행 가능한 스크립트 구조를 짜드리겠습니다.
