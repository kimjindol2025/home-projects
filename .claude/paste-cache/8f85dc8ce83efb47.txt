FreeLang Nexus - V 모드 → C 코드 컴파일러
FreeLang의 V 모드 코드를 실행 가능한 C 코드로 자동 컴파일합니다.

현재 상태: Bus Terminal 완료 | 완성도 98% | 126/126 테스트 통과 ✅ | 7개 언어 @call FFI · Python/Rust/Go/Julia/JS/C/C++ stub 자동 생성 ✅

🎯 주요 기능
1️⃣ Lexer (토큰화)
V 모드 / Python 모드 자동 감지
25+ 키워드, 연산자 지원
문자열, 숫자, 식별자 파싱
2️⃣ Parser (AST 생성)
함수 정의 (매개변수, 반환 타입)
문장 유형: return, assign, if/else
표현식: 이항 연산, 함수 호출
3️⃣ Codegen (C 코드 생성)
V 함수 → C 함수 변환
타입 매핑: i64↔long long, string↔char*
내장 함수 자동 매핑
4️⃣ Runner (컴파일 + 실행)
gcc로 C 코드 컴파일
결과 바이너리 실행
5️⃣ CLI + REPL
nexus run : 파일 실행
nexus compile : C 코드 생성
nexus check : 문법 검사
nexus repl : 대화형 셸
🚌 Bus Terminal (@call)
FreeLang을 중앙 버스 정류장으로 삼아, 7개 언어의 라이브러리를 직접 호출합니다.

@mode(v)

// 외부 언어 라이브러리 호출
@call python:numpy 1.24        // Python numpy → C FFI stub
@call python:numpy as np       // alias 지원
@call rust:rand 0.8            // Rust crate → cbindgen extern
@call go:github.com/gin-gonic/gin  // Go pkg → cgo shared lib
@call julia:Flux               // Julia → julia.h embed
@call js:lodash                // JS → QuickJS embed
@call c:sqlite3                // C 라이브러리 직접 include
@call cpp:vector               // C++ → extern "C" 래퍼

fn main() -> i64 {
  // numpy, rand, gin, Flux... 모두 이 함수에서 사용 가능
  return 0
}
