  🎯 Task 도구 기본 사용법

  1️⃣  TaskCreate - 새 작업 생성

  TaskCreate를 사용해서 새로운 작업을 만듭니다.

  예시:
  - subject: "Phase 7 성능 최적화" (간단한 제목)
  - description: "컴파일 속도 30% 향상, 생성 코드
  최적화" (상세 설명)
  - activeForm: "성능 최적화 진행중" (진행 중일 때
  표시)

  2️⃣  TaskList - 모든 작업 확인

  현재 대기 중인 모든 작업을 봅니다.
  - pending: 대기 중
  - in_progress: 진행 중
  - completed: 완료됨

  3️⃣  TaskGet - 특정 작업 상세 조회

  작업 ID를 사용해서 상세 정보를 확인합니다.
  - 전체 설명
  - 현재 상태
  - 의존성 (blocks, blockedBy)

  4️⃣  TaskUpdate - 작업 상태 업데이트

  작업 진행 상황을 업데이트합니다.

  상태 변화:
  pending → in_progress → completed

  예시:
  - taskId: "1"
  - status: "in_progress" (시작할 때)
  - status: "completed" (완료할 때)
