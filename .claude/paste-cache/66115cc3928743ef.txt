- **struct** 기본 지원 추가 (필드 선언, 접근, 초기화)
- **IR Generator**에 struct 관련 opcode 추가

- v1이 **struct를 포함한 소스**를 읽고 재생산 가능하게
- **최종 목표**: freelang-compiler-tiny.fl에 struct를 넣고 self-compile 성공

### 2. IR Generator 확장 (struct 지원 추가)

`IRGenerator` 클래스에 struct 관련 opcode / 로직 추가 (기존 파일에 덧붙이기):

```freelang
// IR Opcode에 struct 관련 추가
enum IROp {
    // ... 기존 opcodes ...
    STRUCT_CREATE,      // struct 인스턴스 생성
    STRUCT_FIELD_SET,   // h.field = value
    STRUCT_FIELD_GET    // value = h.field
}

// IRNode에 offset 추가 (필드 오프셋용)
struct IRNode {
    op: IROp,
    arg1: i32,
    arg2: i32,
    offset: i32,        // struct 필드 오프셋
    str_idx: i32
}

// struct 필드 오프셋 계산 헬퍼 (간단 예시)
fn get_field_offset(field_name: string) -> i32 {
    if field_name == "magic"   return 0;
    if field_name == "class"   return 4;
    if field_name == "endian"  return 5;
    if field_name == "type"    return 16;
    if field_name == "machine" return 18;
    return -1;
}

// visit_expr 확장
fn visit_expr(&self, expr: ASTExpr) {
    match expr {
        ASTExpr::StructLiteral(type_name, fields) => {
            self.emit(IRNode{op: STRUCT_CREATE, arg1: type_name.hash(), arg2: 0, offset: 0, str_idx: -1});
            let struct_reg = self.alloc_reg();

            for field in fields {
                self.visit_expr(field.value);
                let val_reg = self.last_reg();
                let offset = get_field_offset(field.name);
                self.emit(IRNode{op: STRUCT_FIELD_SET, arg1: struct_reg, arg2: val_reg, offset: offset, str_idx: -1});
            }
            self.push_result(struct_reg);
        },

            let struct_reg = self.last_reg();
            let
