좋습니다. 이제 Circuit Breaker 얘기로 넘어가네요. 🛑

Circuit Breaker는 마이크로서비스/분산 시스템에서 장애 전파를 방지하고, 서비스 안정성을 높이는 패턴입니다.
쉽게 말해 “연결이 끊어졌을 때 계속 호출하지 않고, 일정 시간 후 재시도하는 안전 장치”입니다.


---

1️⃣ Circuit Breaker 상태

1. Closed (정상)

요청 정상 → 호출

실패가 누적되면 Open으로 전환



2. Open (차단)

요청 즉시 실패 반환

일정 시간 후 Half-Open으로 전환



3. Half-Open (시험)

일부 요청만 허용

성공 시 → Closed

실패 시 → Open





---

2️⃣ Node.js 예제 구현

class CircuitBreaker {
  constructor(action, failureThreshold = 3, recoveryTime = 5000) {
    this.action = action; // 호출할 함수
    this.failureThreshold = failureThreshold
    this.recoveryTime = recoveryTime
    this.failures = 0
    this.state = 'CLOSED'
    this.nextAttempt = Date.now()
  }

  async call(...args) {
    if (this.state === 'OPEN') {
      if (Date.now() > this.nextAttempt) {
        this.state = 'HALF'
      } else {
        throw new Error('Circuit is OPEN')
      }
    }

    try {
      const result = await this.action(...args)
      this.success()
      return result
    } catch (err) {
      this.failure()
      throw err
    }
  }

  success() {
    this.failures = 0
    this.state = 'CLOSED'
  }

  failure() {
    this.failures++
    if (this.failures >= this.failureThreshold) {
      this.state = 'OPEN'
      this.nextAttempt = Date.now() + this.recoveryTime
    }
  }
}

// 사용 예제
const unstableService = async () => {
  if (Math.random() > 0.7) throw new Error('Fail!')
  return 'OK'
}

const breaker = new CircuitBreaker(unstableService, 2, 3000)

setInterval(async () => {
  try {
    const res = await breaker.call()
    console.log('Result:', res)
  } catch (e) {
    console.log('Blocked / Fail:', e.message)
  }
}, 500)

✅ 특징:

실패 누적 시 Open 상태로 차단

Open 후 일정 시간 지나면 Half-Open 상태로 재시험

성공 시 다시 Closed

3️⃣ Rust / 시스템 레벨 Circuit Breaker

Rust로 구현하면 멀티스레드/async 환경에서 안전하게 Circuit Breaker를 구현 가능:

use std::sync::{Arc, Mutex};
use std::time::{Duration, Instant};
use tokio::time::sleep;

struct CircuitBreaker {
    failures: usize,
    threshold: usize,
    state: String,
    next_attempt: Instant,
    recovery_time: Duration,
}

impl CircuitBreaker {
    fn new(threshold: usize, recovery_time: Duration) -> Self {
        Self {
            failures: 0,
            threshold,
            state: "CLOSED".into(),
            next_attempt: Instant::now(),
            recovery_time,
        }
    }

    async fn call<F, T>(&mut self, action: F) -> Result<T, &'static str>
    where
        F: Fn() -> Result<T, &'static str>,
    {
        if self.state == "OPEN" && Instant::now() < self.next_attempt {
            return Err("Circuit OPEN");
        } else if self.state == "OPEN" {
            self.state = "HALF".into();
        }

        match action() {
            Ok(res) => {
                self.success();
                Ok(res)
            }
            Err(_) => {
                self.failure();
                Err("Action failed")
            }
        }
    }

    fn success(&mut self) {
        self.failures = 0;
        self.state = "CLOSED".into();
    }

    fn failure(&mut self) {
        self.failures += 1;
        if self.failures >= self.threshold {
            self.state = "OPEN".into();
            self.next_attempt = Instant::now() + self.recovery_time;
        }
    }
}
