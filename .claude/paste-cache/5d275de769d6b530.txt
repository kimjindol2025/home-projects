셀프호스팅(self-hosting) 컴파일러의 **진짜 증명**은 단순히 "작동한다"는 내부 로그나 보고서가 아니라, **외부에서 누구나 독립적으로 재현하고 검증할 수 있는 형태**로 제시하는 것이 핵심입니다.

아래는 실제로 인정받는 프로젝트들(Zig, Go, GCC, CakeML 등)이 사용하는 **표준 증명 방법**을 정리한 것입니다. FreeLang 프로젝트에도 그대로 적용 가능하며, 단계별로 따라가면 "꿈"이 아니라 **객관적 현실**로 만들 수 있어요.

### 1. 기본 증명: E2E 재현 + 출력 증거 (가장 먼저 해야 할 최소 증명)
- hello.free (또는 간단한 test.free) 소스 코드 전체를 공개 (텍스트로 복사 가능)
- 그 소스를 FreeLang 컴파일러로 컴파일해서 생성된 hello.elf (또는 a.out) 파일의 **hex dump** 또는 **base64 인코딩** 공개
  - 예: `xxd -g1 hello.elf` 또는 `base64 hello.elf` 결과
- ELF 파일 실행 결과 증거
  - `./hello.elf` 또는 `./a.out` 실행 → "Hello, FreeLang!" 또는 예상 출력 캡처 (터미널 스크린샷 + 로그)
- ELF 파일 정보 확인
  - `file hello.elf` → "ELF 64-bit LSB executable, x86-64" 출력
  - `readelf -h hello.elf` 또는 `objdump -d hello.elf` 일부 공개 (특히 .text 섹션에 printf 호출 보이는지)

이 단계만으로도 "최소한 hello world는 컴파일 → 실행된다"는 증명이 됩니다. (많은 tiny self-hosting 프로젝트가 이 수준에서 공개)

### 2. 진짜 self-hosting 증명: Fixed-point (고정점) 도달 증명
이게 **핵심**이자 사람들이 "진짜 self-hosting이네"라고 인정하는 부분입니다.

- FreeLang 소스 전체 (self-lexer.fl ~ self-elf-header.fl 포함)를 **현재 컴파일러**로 컴파일 → free-lang-compiler-v1 (바이너리1 생성)
- 그 바이너리1로 **같은 FreeLang 소스 전체**를 다시 컴파일 → free-lang-compiler-v2 (바이너리2 생성)
- 바이너리1과 바이너리2의 **파일 내용이 완전히 동일**함을 증명
  - `md5sum free-lang-compiler-v1 free-lang-compiler-v2` 또는 `sha256sum` 결과가 똑같아야 함
  - 또는 `cmp -l v1 v2` → 차이 없음 출력

이 과정을 **3-stage bootstrap**처럼 확장하면 더 신뢰 ↑
- Stage 1: 기존 Node.js/TS 버전으로 컴파일 → bin1
- Stage 2: bin1로 FreeLang 소스 컴파일 → bin2
- Stage 3: bin2로 다시 FreeLang 소스 컴파일 → bin3
- bin2 == bin3 (고정점 도달) → 성공 증명

Zig, GCC, CakeML 등이 이 방법을 사용합니다.

### 3. 신뢰성 추가 증명 방법 (고급 / 선택)
- **Reproducible build** 증명
  - Docker 이미지나 정확한 빌드 명령어 + seed + 환경 변수 공개
  - 누구나 같은 입력 → 같은 hello.elf / compiler 바이너리 생성됨을 보장
- **Deterministic output** 확인
  - 같은 소스 → 항상 동일한 ELF 바이너리 (타임스탬프, 랜덤성 제거)
- **Reflections on Trusting Trust 방지**
  - 소스 코드에 숨겨진 백도어가 없는지, **다른 독립 컴파일러**(gcc, zig 등)로도 같은 바이너리 나오는지 비교 (선택적, 고난이도)
- **공개 저장소 + CI 증명**
  - GitHub/GitLab public mirror 올리기
  - GitHub Actions나 GitLab CI에서 bootstrap 과정 자동 실행 → 성공 로그 공개

### 실천 가능한 가장 빠른 시작 순서 (당신 프로젝트에 추천)
1. **hello.free** 파일 하나 + 그걸 컴파일한 **hello.elf** hex dump (xxd -g1 또는 base64) + 실행 스크린샷 → 지금 당장 공유 가능
2. FreeLang 컴파일러 바이너리 하나 (현재 작동하는 버전) + 그걸로 **자기 자신 컴파일**해서 나온 바이너리와 md5 비교 결과
3. 위 두 가지를 README나 별도 md 파일에 넣고 Gogs 저장소 public mirror 생성 (또는 zip으로 공유)

이 정도만 해도 "이건 진짜 self-hosting 맞네"라는 반응이 나옵니다. (실제로 Zig 초기 버전이나 tiny C 컴파일러 프로젝트들이 이 방식으로 신뢰 쌓음)
