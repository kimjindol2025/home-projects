3단계 메모리 관리 아키텍처 분석
코드 복사

Level 3: Heap Allocator (동적 메모리)
Level 2: Paging System (가상 → 물리 주소 변환)
Level 1: Physical Memory (물리 메모리 페이지 관리)
1️⃣ 물리 메모리 관리 (Level 1)
구조체
Rust
코드 복사
struct PhysicalPage {
    page_number: u64,
    page_size: u64,      // 4KB
    phys_addr: u64,
    allocated: bool,
}
특징
4KB 단위 페이지 관리
페이지 번호로부터 물리 주소 계산: phys_addr = page_number * 4096
O(1) 할당/해제 가능
서버/시스템 RAM에 직접 대응 → 최소 단위: 4KB 페이지
장점
단순, 빠른 주소 계산
연속 메모리 할당 시 캐시 친화적
단점
페이지 크기 고정 → 작은 객체 처리 비효율 가능
프래그멘테이션 추적이 없음
2️⃣ 페이징 시스템 (Level 2)
구조체
Rust
코드 복사
struct PageTableEntry {
    physical_addr: u64,
    present: bool,
    writable: bool,
    user_accessible: bool,
    accessed: bool,
    dirty: bool,
}

struct PageTable {
    entries: Vec<PageTableEntry>,  // 512 entries
    process_id: u32,
}
알고리즘
가상 → 물리 주소 변환 (O(1))
Text
코드 복사
index = (virtual_addr / 4096) % 512
offset = virtual_addr % 4096
phys_addr = page_table[index].physical_addr + offset
페이지 매핑 (Mapping)
page_table[index].physical_addr = phys_addr
present = true
페이지 언매핑 (Unmapping)
present = false
페이지 폴트(Page Fault) 발생 가능
장점
O(1) 직접 인덱싱 → 빠른 주소 변환
읽기/쓰기/사용자 접근 권한 통제
Dirty/Accessed 플래그 → 스왑, LRU 정책 적용 가능
제약
512개 엔트리 → 기본 2MB 가상 공간 (512 * 4KB)
단일 레벨 → 큰 프로세스에 확장 필요 → 다단계 페이지 테이블 필요
스왑/메모리 압축 미구현
3️⃣ 힙 할당자 (Level 3)
구조체
Rust
코드 복사
struct MemoryBlock {
    start_addr: u64,
    size: u64,
    allocated: bool,
}

struct HeapAllocator {
    blocks: Vec<MemoryBlock>,
    total_size: u64,
    allocated_size: u64,
}
할당 알고리즘: First Fit
Text
코드 복사
for block in blocks:
    if block.free and block.size >= request:
        allocate block

Text
코드 복사
for block in blocks:
    if block.start_addr == addr and block.allocated:
        block.allocated = false

📊 메모리 레이아웃 예시
코드 복사

0x00000000 ┌────────────────────────────┐
            │ MBR / Boot Sector          │
0x00007C00  │ IDT (512 bytes)            │
0x00100000  │ Kernel Code & Data (1MB)   │
0x00200000  │ Heap / Dynamic Memory (510MB) │
0x20000000  │ Unmapped / 보호 영역       │
이 구조를 기반으로 kernel.fl과 통합하면:
Kernel은 Level 1/2/3 계층을 모두 활용
HeapAllocator는 커널/프로세스 동적 메모리 제공
PageTable은 프로세스 가상 주소 관리
PhysicalPage Table은 실제 RAM 추적
