### Stage 7 목표 (제안)

1. **이항 연산자 지원**  
   - `p.x + p.y`, `p.x * 2` 등 기본 산술 연산  
   - 이를 통해 struct 필드를 실제 계산에 활용 가능

2. **v1 → v2 → v3 실제 체인 구성 준비**  
   - v1.elf이 struct를 포함한 소스를 읽고 → v2.elf 생성  
   - v2.elf 실행 → v3.elf 생성  
   - v2 ≡ v3 확인 (진정한 bootstrap)

3. **최소 테스트 케이스**  
   - struct 필드 값을 계산해서 출력하는 ELF 생성  
   - 이 ELF가 스스로를 재생산하는 최소 증명

### Stage 7 코드 제시 (freelang-compiler-tiny.fl)

```freelang
// freelang-compiler-tiny.fl - Stage 7: Binary Operators + Bootstrap 준비

struct Point {
    x: i32,
    y: i32
}

fn add_points(a: Point, b: Point) -> Point {
    let result: Point;
    result.x = a.x + b.x;
    result.y = a.y + b.y;
    return result;
}

fn print_point(p: Point) {
    println("Point { x: " + p.x + ", y: " + p.y + " }");
}

fn main() {
    println("FreeLang Tiny Self-Hosting Stage 7");
    println("이항 연산자 + struct 계산 증명");

    let p1: Point;
    p1.x = 10;
    p1.y = 20;

    let p2: Point;
    p2.x = 30;
    p2.y = 40;

    let sum: Point = add_points(p1, p2);

    print_point(sum);                 // Point { x: 40, y: 60 }

    // 계산 결과 검증
    let total = sum.x + sum.y;        // 100
    println("Total: " + total);

    // self-hosting 증명을 위한 메시지
    println("Stage 7 success: binary operators on struct fields working");

    return 0;
}
```

### Parser 확장 (이항 연산자 지원)

`parseExpression` 계층을 확장하여 **+ - * /** 우선순위 처리:

```freelang
// parseExpression → parseAdditiveExpression → parseMultiplicative → parsePrimary
fn parseAdditiveExpression(&self) -> ASTExpr {
    let left = self.parseMultiplicativeExpression();

    while (self.current().value == '+' || self.current().value == '-') {
        let op = self.current().value;
        self.advance();
        let right = self.parseMultiplicativeExpression();
        left = ASTExpr::Binary(op, left, right);
    }
    return left;
}

fn parseMultiplicativeExpression(&self) -> ASTExpr {
    let left = self.parsePrimaryExpression();

    while (self.current().value == '*' || self.current().value == '/') {
        let op = self.current().value;
        self.advance();
        let right = self.parsePrimaryExpression();
        left = ASTExpr::Binary(op, left, right);
    }
    return left;
}
```

### IR Generator 확장 (Binary 연산)

```freelang
fn visit_expr(&self, expr: ASTExpr) {
    match expr {
        ASTExpr::Binary(op, left, right) => {
            self.visit_expr(left);
            let left_reg = self.last_reg();
            self.visit_expr(right);
            let right_reg = self.last_reg();
            let dest_reg = self.alloc_reg();

            match op {
                "+" => self.emit(IROp::ADD, left_reg, right_reg, dest_reg, -1),
                "-" => self.emit(IROp::SUB, left_reg, right_reg, dest_reg, -1),
                "*" => self.emit(IROp::MUL, left_reg, right_reg, dest_reg, -1),
                "/" => self.emit(IROp::DIV, left_reg, right_reg, dest_reg, -1),
            }
            self.push_result(dest_reg);
        },
        // 기존 struct, 배열 처리 유지
    }
}
```
