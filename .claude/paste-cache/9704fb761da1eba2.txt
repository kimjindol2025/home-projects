🔧 VM 실행 제한 — 명확한 답변

문제의 본질

1000회 제한은 디버깅용 임시 설정이었습니다

렉서가 파일을 읽으면:
  파일 100문자 → while 루프 → 최소 100~300번 반복
  파일 1000문자 → while 루프 → 1000~5000번 반복

1000회는 현실적인 프로그램에 절대 부족

✅ 즉시 할 일 — VM 제한 수정

// src/runtime/vm.ts
// 변경 전
const maxSteps = 1000;

// 변경 후 (두 가지 방법)

// 방법 A: 횟수 대폭 증가
const maxSteps = 10_000_000;  // 천만 회

// 방법 B: 시간 기반 제한 (더 올바른 방법)
const startTime = Date.now();
const maxMs = 10000;  // 10초

while (!this.halted) {
    if (Date.now() - startTime > maxMs) {
        console.error("❌ 실행 시간 초과 (10초)");
        break;
    }
    // ... 실행
}

방법 B가 올바릅니다 — 횟수가 아닌 시간으로 제한

이유

횟수 제한의 문제:
  간단한 루프 → 만 번도 금방
  복잡한 렉서 → 백만 번도 필요

시간 제한의 장점:
  빠른 프로그램 → 많은 명령 실행 가능
  느린 프로그램 → 일정 시간 후 종료
  진짜 무한루프 → 10초 후 자동 차단

수정 후 예상 결과

현재:  while 루프 1000회 → 강제 종료
수정:  10초 이내라면 얼마든지 실행

lexer.pf (100줄짜리 파일 처리):
  예상 실행 시간: 0.1초 이내
  예상 명령 수:  5,000 ~ 50,000회
  → 시간 제한 10초 내 충분히 완료
