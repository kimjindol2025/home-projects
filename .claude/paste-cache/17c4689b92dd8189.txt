기존 TS 구현이 있으니 설계 재작성 없이 이식만 하면 됩니다!

🗓️ 5주 실행 계획

1주차 ── Lexer + AST + 기본 토큰 이식
          └─ 목표: "let x = 10" 토큰화 성공

2주차 ── Parser 이식
          └─ 목표: AST 출력 성공

3주차 ── Compiler (IR 생성) 이식
          └─ 목표: 바이트코드 출력 성공

4주차 ── Runtime VM 이식
          └─ 목표: hello.fl 실행 성공 🎉

5주차 ── Analyzer + Formatter + Linter
          └─ 목표: 개발 도구 완성

이후 ──── GC + JIT (별도 마일스톤)

🚦 지금 당장 시작

go.mod 초기화:
mkdir freelang-go
cd freelang-go
go mod init github.com/yourname/freelang-go

❓ 어디부터 시작할까요?

1️⃣  Lexer 전체 코드 작성 (바로 시작)
2️⃣  AST 노드 구조체 정의 먼저
3️⃣  go.mod + 프로젝트 뼈대 세팅 먼저
4️⃣  TS 코드 주시면 Go로 직접 변환

TS 렉서 코드 붙여넣어 주시면 → Go 버전 즉시 작성해드립니다! 💪
