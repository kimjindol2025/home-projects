GOGS 푸시 방법

  1단계: Remote 확인

  git remote -v
  출력:
  gogs  https://gogs.dclub.kr/kim/freelang-v2.git
  (fetch)
  gogs  https://gogs.dclub.kr/kim/freelang-v2.git
  (push)

  2단계: 푸시

  git push gogs master

  옵션:
  - -v: 상세 출력
  - -u: upstream 설정 (처음 한 번만)
  git push -u gogs master

  3단계: 확인

  GOGS 서버에서 확인:
  https://gogs.dclub.kr/kim/freelang-v2

  ┌─────┬───────────────────┬─────────────────────┐
  │ 항  │       GOGS        │       GitHub        │
  │ 목  │                   │                     │
  ├─────┼───────────────────┼─────────────────────┤
  │ 주  │ https://gogs.dclu │ git@github.com:kimj │

  ├─────┼───────────────────┼─────────────────────┤
  │ 인  │ HTTPS (자동)      │ SSH 키 (복잡)       │
  │ 증  │                   │                     │
  ├─────┼───────────────────┼─────────────────────┤
  │ 속  │ 내부 네트워크     │ 외부 (느림)         │
  │ 도  │ (빠름)            │                     │
  ├─────┼───────────────────┼─────────────────────┤
  │ 용  │ 내부 배포         │ 공개 공유           │
  │ 도  │                   │                     │
  └─────┴───────────────────┴─────────────────────┘

  자주 쓰는 명령어

  # GOGS로 푸시
  git push gogs master

  # GitHub로 푸시
  git push origin master

  # 모두 푸시
  git push gogs master && git push origin master

  # 특정 브랜치만
  git push gogs develop

  # 태그 푸시
  git push gogs v2.10.0
