1️⃣ 계산 = 시간 위의 기하학 (Temporal Geometry Model)

기존 모델:

입력 → 계산 → 출력

새 모델:

공간 S 위의 상태가
시간 축 T 를 따라
연속적으로 변형됨

프로그램은 함수가 아니라:

Φ : (S × T) → S

의미:

상태는 고정된 값이 아니라

“시간에 따라 정의되는 다양체”


이건 함수형 패러다임을 초월한다.


---

2️⃣ 계산 = 자원 보존 법칙

기존 언어:

메모리는 구현 세부사항


새 모델:

모든 계산은 자원 보존 방정식을 만족해야 한다.

R_before = R_after + Δ

여기서 R:

메모리

에너지 비용

통신량

시간 비용


자원은 타입에 포함된다.

A ⊢ e : B ⊣ ΔR

이건 단순 선형 타입이 아니라
물리적 계산 모델이다.

철학적 기반은:

Linear Logic



---

3️⃣ 값 제거 — 관계 중심 의미론

기존:

f(x) = y

새 모델:

R(x, y)

계산은 함수가 아니라 관계.

출력은 “결정”이 아니라 “수렴”.

이건

Constraint Satisfaction Problem

Fixed Point (mathematics)


기반 모델로 간다.


---

4️⃣ 실행 개념 제거

프로그램은 “실행”되지 않는다.

프로그램은 제약 시스템이다.

컴파일러는:

방정식 시스템 구성

최소 에너지 상태 탐색

수렴점 계산


즉:

Program = Equation System
Execution = Convergence

이건 완전히 다른 세계관이다.


---

5️⃣ 시간, 자원, 관계 통합 구조

최종 모델:

Σ = (S, T, R, C)

S: 상태 공간
T: 시간 흐름
R: 자원 벡터
C: 제약 집합

계산은:

Solve(Σ) → Stable Manifold

이건 더 이상

Turing Machine

Lambda Calculus


모델이 아니다.
