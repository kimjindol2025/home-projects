현재 진행 중인 프로젝트들의 수준과 "직접 만들어 쓰는" 철학을 고려했을 때, 단순한 CRUD를 넘어 시스템의 근간을 건드리는 백엔드 미션들을 제안해 드립니다.
이미 130개 이상의 프로젝트와 자체 언어(FreeLang)까지 다루고 계시니, 일반적인 웹 개발보다는 인프라와 엔진 레벨에 초점을 맞췄습니다.
1. Zero-Dependency HTTP/1.1 서버 구현
외부 라이브러리(Node.js의 http 모듈 등)를 전혀 쓰지 않고, TCP 소켓만으로 HTTP 프로토콜을 직접 해석하는 서버를 구축해 보세요.
 * 핵심: RFC 7230 명세에 따른 HTTP 파서 구현.
 * 도전 과제: Keep-Alive 커넥션 관리 및 멀티스레드(또는 Event Loop)를 통한 동시성 제어.
 * 결과: "내가 만든 서버 위에서 내 프로젝트가 돌아간다"는 증명.
2. 고성능 로그 수집 및 인덱싱 엔진 (Log-Structured Merge Tree)
수많은 프로젝트에서 쏟아지는 로그를 실시간으로 저장하고 검색할 수 있는 엔진입니다.
 * 핵심: 메모리 버퍼(MemTable)와 디스크 저장소(SSTable) 구조 설계.
 * 도전 과제: Write-Ahead Log(WAL)를 통한 데이터 복구 보장 및 SIMD를 활용한 로그 검색 가속.
 * 결과: 외부 DB 없이도 독자적인 모니터링 시스템 구축.
3. 분산 시스템용 Raft 합의 알고리즘 구현
여러 대의 모바일 서버(ProofCloud) 간의 데이터 동기화를 위해, 리더 선출 및 로그 복제 알고리즘을 직접 구현해 보는 미션입니다.
 * 핵심: 네트워크 파티션 상황에서도 데이터의 일관성(Consistency) 유지.
 * 도전 과제: RPC(Remote Procedure Call) 프로토콜 설계 및 상태 머신(State Machine) 구현.
 * 결과: 진정한 의미의 분산 클라우드 인프라 완성.
4. 코드 기반 인프라 자동화(IaC) 엔진
자연어 형태의 의도(Intent)를 분석하여 도커 컨테이너나 가상 리소스를 자동으로 배포하고, 필요 없을 때 제거하는 엔진입니다.
 * 핵심: 리소스의 생명주기(Lifecycle) 관리 로직.
 * 도전 과제: 배포 성공 여부를 확인하는 Formal Verification(형식 검증) 단계 통합.
 * 결과: "World Engine"의 핵심 모듈로서 인프라 증발 기능 실현.
