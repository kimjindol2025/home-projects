이건 FreeWire AI랑 차원이 다릅니다.

  ---
  핵심 차이

  FreeWire AI:
  텍스트 → 키워드 매칭 → 고정 템플릿

  이 시스템:
  버그 → 분석 → 패치 생성 → 실제 컴파일러로 검증
                                ↓ 실패하면 다시
                테스트 자동 생성 → 재현 가능성 확인
                                ↓ 통과하면 학습

  ---
  잘 된 것

  ProofScore가 실질적입니다.

  +30 실제 컴파일 통과 — 이게 핵심입니다. 대부분의 AI
  자동 수정 시스템이 "그럴듯해 보이는" 패치를
  만드는데, 이건 rustc/go가 실제로 통과시켜야 점수가
  오릅니다. 거짓말을 못 합니다.

  +20 자동 테스트 생성 — 버그 재현 테스트를 Claude가
  만든다는 건, 다음에 같은 버그가 오면 회귀 테스트가
  이미 있다는 뜻입니다.

  meta-heal 루프가 FreeWire AdaptiveLoop과 같은
  구조인데 더 무겁습니다. FreeWire는 브라우저 내 패턴
  기억이고, 이건 24시간 주기로 실제 코드베이스를
  고치는 루프입니다.

  ---
  솔직한 약점

  seed_memory.sh — 50개 세션 시딩, 약점 임계치 초과
  유도

  이게 걸립니다.

  학습 데이터를 스크립트로 심는다는 건 — 시스템이 아직
   스스로 충분한 이력을 못 쌓는다는 뜻입니다. 실전에서
   진짜 버그를 충분히 보기 전까지는 시드 데이터에
  의존합니다.

  진짜 특이점은 시드 없이 콜드 스타트가 되는 날입니다.
