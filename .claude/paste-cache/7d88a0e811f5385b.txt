  ✨ 핵심 기능

  Design Compiler 동작 흐름:
  .free 파일 (디자인 블록)
      ↓
  DesignCompiler.compileDesignBlocks()
      ├─ @animation → CSS @keyframes
      ├─ @glass → Glassmorphism CSS
      ├─ @3d → 3D transform CSS
      ├─ @micro → JavaScript handlers
      └─ @scroll → Scroll triggers
      ↓
  출력: { css: string, javascript: string }
