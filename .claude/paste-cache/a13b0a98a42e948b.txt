🏗️ Stage 2: FreeLang Runtime 구현 (Week 3-4)
바이너리 아키텍처와 상관없이, 언어의 심장인 Runtime을 구축하는 것은 현재 환경에서도 100% 가능하며 가장 시급한 과제입니다.
1. 구현 핵심 명세 (Zero-Dependency 원칙)
 * Memory Management: 외부 libc 없이 직접 구현하는 malloc()과 free(). (SBRK 또는 MMAP 시스콜 활용)
 * System Calls: syscall() 인터페이스를 통해 OS와 직접 대화하는 로직.
 * String/Array Handling: str_len(), arr_new() 등 기본 자료구조 운영 함수.
2. 작업 환경 및 규모
 * 언어: FreeLang v6 (Self-hosted)
 * 목표: 약 500줄의 순수 로직, 10개 이상의 유닛 테스트 통과.
 * 검증: 현재 ARM64 환경에서 컴파일 및 로직 테스트 우선 진행.
