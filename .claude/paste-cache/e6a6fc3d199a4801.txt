### 1. FreeLang 내장 문자열/컬렉션 함수 확인 & 대응 전략

당신이 언급한 함수들 중 FreeLang 런타임에서 실제 이름이 어떻게 되어 있는지 확인이 핵심이에요.  
현재 builtins.test.ts나 stdlib-builtins.ts 로그를 보면 아래 패턴이 보입니다:

| 당신이 parser.fl에서 쓴 이름 | 가장 유력한 실제 이름 (v2 기준)          | 대체/확인 방법                                      | 즉시 수정 추천 |
|-------------------------------|-------------------------------------------|-----------------------------------------------------|----------------|
| strlen()                      | str.length 또는 len(str)                  | arr.length처럼 len() 통합 가능성 높음               | len()으로 교체 시도 |
| str_at(source, pos)           | str.char_at(source, pos) 또는 source[pos] | char_at()이 표준으로 보임 (예제에 등장)            | char_at() 유지 또는 [] 시도 |
| char_code()                   | str.char_code_at() 또는 없음              | JS charCodeAt() 비슷 → 구현 안 됐을 수 있음        | 일단 0으로 mock하거나 구현 지연 |
| map_new()                     | map_new()                                 | stdlib-aliases.ts에 명확히 등록됨 → 그대로 OK       | 변경 없음 |
| has_key(map, key)             | map.has(key) 또는 map_contains()          | JS Map.has() 스타일 → map.has() 가능성 높음         | map.has()로 교체 추천 |
| push(arr, item)               | arr.push(item) 또는 append()              | arr.push()가 builtins에 등록됨                      | arr.push()로 교체 |

**즉시 해볼 수 있는 3분 체크 리스트** (FreeLang REPL이나 test 파일로)

```fl
fn check_builtins() {
  println(len("hello"))                    # 5 기대
  println(char_at("hello", 1))             # 'e' 기대 (또는 str_at)
  let m = map_new()
  m["key"] = 42
  println(m.has("key"))                    # true 기대 (또는 has_key)
  
  let a = []
  a.push(100)
  println(arr_length(a))                   # 1 기대
}
```

→ 위 코드 실행해서 에러 나는 부분이 있으면 그게 바로 교체 대상입니다.

### 2. hello.fl 수동 토큰 검증 (정신 체크용)

당신이 쓴 hello.fl 예시 기준 기대 토큰 14개는 거의 정확해 보입니다.  
정리된 버전 (위치 무시, 타입만):

```
1.  FN
2.  IDENT        "hello"
3.  INPUT
4.  IDENT        "name"
5.  COLON
6.  IDENT        "string"
7.  OUTPUT
8.  IDENT        "string"
9.  INTENT
10. STRING       "인사말"
11. RETURN
12. STRING       "Hello, "
13. PLUS
14. IDENT        "name"
15. EOF          (추가)
```

→ 만약 tokenize("hello.fl 내용") 결과가 14~15개 나오고 위 순서/값이 맞으면 **lexer 신뢰도 95% 이상** 확보한 겁니다.
