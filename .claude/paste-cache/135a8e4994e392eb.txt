프론트엔드 개발은 단순히 눈에 보이는 화면을 만드는 것을 넘어, 사용자와 애플리케이션이 상호작용하는 모든 기술적 영역을 포함합니다. 크게 핵심 기술, 프레임워크, 상태 관리, 빌드 도구로 나누어 살펴볼 수 있습니다.
1. 3대 핵심 기술 (The Big Three)
모든 프론트엔드의 기초이자 뼈대입니다. 이 기술들은 브라우저가 직접 해석할 수 있는 언어들입니다.
 * HTML (HyperText Markup Language): 웹페이지의 구조와 콘텐츠를 정의합니다. (제목, 문단, 버튼 등)
 * CSS (Cascading Style Sheets): 디자인과 레이아웃을 담당합니다. (색상, 폰트, 애니메이션, 반응형 디자인)
 * JavaScript (JS): 동적인 기능을 구현합니다. (데이터 클릭 이벤트, 서버 통신, 실시간 화면 업데이트)
2. 현대적 프레임워크 및 라이브러리
복잡한 UI를 효율적으로 관리하기 위해 사용하며, 현재 시장은 '3대장' 체제입니다.
 * React: 컴포넌트 기반으로 재사용성이 높고 생태계가 가장 큽니다. (Meta 개발)
 * Vue.js: 학습 곡선이 낮고 깔끔한 문법을 자랑합니다.
 * Angular: 대규모 엔터프라이즈 앱에 적합한 강력한 기능을 갖춘 풀 프레임워크입니다. (Google 개발)
 * Next.js: React 기반이지만 서버 사이드 렌더링(SSR)과 SEO 최적화에 특화되어 최근 가장 선호되는 도구입니다.
3. 상태 관리 및 데이터 통신
사용자가 입력한 정보나 서버에서 가져온 데이터를 어떻게 관리할지 결정합니다.
 * 상태 관리 (State Management): Redux, MobX, Recoil, Zustand 등을 통해 앱 전체의 데이터를 체계적으로 관리합니다.
 * API 통신: Axios나 Fetch API를 사용하여 백엔드 서버와 데이터를 주고받습니다.
 * 데이터 페칭 라이브러리: React Query(TanStack Query)나 SWR을 사용하여 캐싱 및 실시간 데이터 업데이트를 처리합니다.
4. 빌드 도구 및 환경 (Tooling)
코드를 최적화하고 브라우저가 읽기 좋은 형태로 변환해줍니다.
 * 패키지 매니저: npm, yarn, pnpm (라이브러리 설치 및 관리)
 * 번들러: Webpack, Vite (여러 파일을 하나로 합치고 용량 압축)
 * 컴파일러: Babel (최신 JS 코드를 구형 브라우저용으로 변환), TypeScript (자바스크립트에 타입을 입혀 오류 방지)
💡 한눈에 보는 프론트엔드 구조
| 구분 | 주요 기술 | 역할 |
|---|---|---|
| 기초 | HTML, CSS, JavaScript | 화면의 뼈대, 근육, 신경계 |
| 프레임워크 | React, Vue, Next.js | 효율적인 개발을 위한 틀 |
| 스타일링 | Tailwind CSS, Sass, Styled-components | 디자인 생산성 향상 |
| 언어 확장 | TypeScript | 코드 안정성 및 유지보수성 강화 |
