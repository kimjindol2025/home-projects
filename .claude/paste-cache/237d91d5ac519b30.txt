**젠스파크(Genspark)**는 2026년 현재 가장 핫한 **올인원 AI 워크스페이스 + 슈퍼 에이전트** 플랫폼 중 하나예요.  
당신의 프로젝트( FreeWire, self-healing 에이전트, sovereign 루프 등)와 비교하면 **상당히 비슷한 방향성**을 가진 서비스라서, "이런 게 이미 시장에 나와 있구나" 하면서도 **차별화 포인트**를 찾기 좋은 벤치마크가 됩니다.

### Genspark 주요 특징 (2026년 3월 기준)
- **올인원 AI 워크스페이스**: 한 곳에서 슬라이드·문서·시트·코드·이미지·영상·음악·디자인·코딩까지 다 처리.
  - AI Slides / AI Sheets / AI Docs / AI Designer / AI Chat / AI Image / AI Video / AI Music 등.
- **Super Agent / Claw AI** — 진짜 강점: 단순 채팅이 아니라 **실제 행동(autonomous action)** 하는 에이전트.
  - 프롬프트 하나로 전화 걸기, 회의 자동 참여·녹음·메모 작성, 웹 조사·요약, 복잡한 태스크 자동화.
  - Speakly: 음성 입력 → 세련된 텍스트/이메일/문서 변환 (타이핑 4배 빠름).
  - 브라우저 확장 + Autopilot 모드: 웹페이지 자동 요약·쇼핑 비교·리뷰 분석 등.
- **브라우저 버전**: Genspark AI Browser (온디바이스 AI, 무료 로컬 모델, 애드블록, Super Agent 내장).
- **성장 속도**: 2023년 창업 → 10개월 만에 ARR 1.55억 달러 (약 2,000억 원) 돌파, 시리즈 B 3억 8,500만 달러 투자 유치 (OpenAI, Anthropic, Microsoft 등 파트너십).
  - 사용자 200만+ , 기업 1,000+ 온보딩 (2026년 1월 기준).
- **가격/접근성**: 무료 시작 가능 + Plus/Pro 플랜 (2026년 내내 AI Chat & Image 무제한 프로모션 중인 듯).
  - 앱: iOS / Android / Web / 브라우저 확장.

### 당신 프로젝트와 비교하면?
- **공통점** (놀랄 정도로 비슷)
  - 자연어 → 자동 생성 (FreeWire의 AI 노드 생성 vs Genspark의 Super Agent)
  - 반복/복잡 태스크 자동화 (self-healing 루프 vs Claw AI의 autonomous execution)
  - Intent/목표 기반 동작 (Intent First-Class vs Genspark의 에이전트 reasoning)
  - 브라우저 중심 + self-hosted 느낌 (personal-code-os vs Genspark Browser 온디바이스 AI)
- **당신이 더 강한 부분** (차별화 기회)
  - **완전 self-hosted / sovereign** 방향: Genspark은 클라우드 중심 (Claude/OpenAI 등 의존), 당신 건은 로컬-first + Gogs mirror + zero-dep 가능.
  - **코드 중심 self-healing**: Genspark은 일반 업무 자동화가 강하지만, 당신의 ProofScore + multi-agent heal (Rust/Go 버그 자동 fix)은 **개발자 특화**로 차별화.
  - **언어/컴파일러 통합**: fv-lang + WASM + self-bootstrap → Genspark에는 없는 "코드가 스스로 진화하는" 깊이.
  - **오픈소스 가능성**: Genspark은 클로즈드, 당신 건은 공개하면 커뮤니티 빌드 + 포크 가능.

### 결론: Genspark은 "당신이 만들고 있는 미래의 미리보기" 같은 서비스
- 이미 시장에서 검증된 모델 (빠른 성장 + 빅테크 파트너십).
- 하지만 당신의 sovereign / self-evolving / 코드 특화 방향은 아직 Genspark이 따라오지 못하는 영역 → **여기서 차별화하면 진짜 경쟁 우위** 나옴.
- 다음 프로젝트 아이디어로: **"Genspark-like 올인원 워크스페이스지만, 완전 로컬 + self-healing 코드 중심"** 버전 만들기 (FreeWire + self-healing + personal-code-os 통합).
