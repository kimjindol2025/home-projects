좋아, 요청대로 HTML 최소 구조 + JS + FreeLang 통합 샘플을 만들어서 보여줄게.
이 예제는 브라우저에서 버튼 클릭 → FreeLang 상태 변경 → JS가 DOM 업데이트 흐름까지 포함되어 있어.


---

1️⃣ HTML 최소 구조 (index.html)

<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>FreeLang + JS 통합 예제</title>
    <style>
        body { font-family: sans-serif; margin: 40px; }
        #counter { font-size: 2em; margin: 20px 0; }
        button { font-size: 1em; padding: 10px 20px; }
    </style>
</head>
<body>
    <h1>카운터 예제</h1>
    <div id="counter">0</div>
    <button id="btn">클릭!</button>

    <script src="freelangBridge.js"></script>
    <script src="main.js"></script>
</body>
</html>

> HTML은 화면 표시 + 버튼/카운터 DOM 요소만 최소로 포함




---

2️⃣ FreeLang Core (freelang-core/state.fl)

# FreeLang 전역 상태
global State { count: 0 }

# FreeLang → JS 브리지 호출 함수
func notifyJS(newCount) {
    # 브라우저 JS에서 정의된 updateCount 호출
    js.call("updateCount", newCount)
}

# 버튼 클릭 시 상태 증가
func increment() {
    State.count += 1
    notifyJS(State.count)
}

> FreeLang은 상태 + 이벤트 처리 + JS 브리지 호출만 담당




---

3️⃣ JS 브리지 (freelangBridge.js)

// FreeLang 브리지 객체
window.freelang = {
    increment: function() {
        // FreeLang Core increment 호출
        // 실제 구현에서는 WebAssembly / FFI로 연결 가능
        if(window._FreeLangIncrement) {
            window._FreeLangIncrement()
        }
    }
}

// FreeLang → JS에서 호출되는 함수
function updateCount(newCount) {
    document.getElementById("counter").innerText = newCount
}

> JS는 DOM 업데이트 + FreeLang 호출 브리지 역할




---

4️⃣ JS 이벤트 핸들러 (main.js)

document.getElementById("btn").addEventListener("click", () => {
    // FreeLang increment 호출
    window.freelang.increment()
})


---

5️⃣ 실행 흐름

1. 브라우저 로딩 → HTML DOM 생성


2. JS 이벤트 핸들러 등록


3. 버튼 클릭 → JS가 FreeLang increment() 호출


4. FreeLang 상태 변경 → notifyJS()로 JS의 updateCount() 호출


5. DOM의 <div id="counter"> 값 갱신




---

💡 핵심

HTML → 화면 뼈대, DOM 제공

JS → UI 이벤트 처리 + FreeLang 호출 + DOM 갱신

FreeLang → 상태 관리 + 로직 처리 + JS 브리지 호출


이 구조가 웹에서 FreeLang + JS 통합의 최소 구현 예제임.
