### 🛤️ 셀프호스팅 구현 순서

#### **1단계: `lexer.pf` — 소스 파일 토큰화**

지금 PyFree의 파일 I/O가 완성됐으니 가장 먼저 구현 가능한 것입니다.

```
핵심 기능:
- 소스 파일 읽기 (이미 구현됨! ✅)
- 문자 스트림 → 토큰 리스트
- 키워드, 식별자, 숫자, 연산자 분류
- 줄/열 번호 추적 (에러 메시지용)
```

#### **2단계: `parser.pf` — 토큰 → AST**

```
핵심 기능:
- 재귀 하강 파서 (딕셔너리로 AST 노드 표현 ✅)
- 표현식 파싱 (연산자 우선순위)
- 문장 파싱 (if, while, func 등)
- AST 딕셔너리 구조로 출력
```

#### **3단계: `compiler.pf` — AST → IR/코드**

```
핵심 기능:
- AST 순회 (재귀)
- 코드 생성 또는 인터프리터
- 파일 I/O로 결과 출력 ✅
```

### 💡 전략적 조언

**딕셔너리로 AST 표현** (클래스 없이도 충분!)

```python
# PyFree 스타일로 AST 노드 표현 예시
node = {
    "type": "BinaryOp",
    "op": "+",
    "left": {"type": "Number", "value": 1},
    "right": {"type": "Number", "value": 2}
}
```

→ 클래스 없이 딕셔너리만으로 완전한 AST 구현 가능! 🎯
