✅ PyFree 셀프호스팅 완성 체크리스트

셀프호스팅이 "진정으로 완성"되었는지 검증하는 마스터 체크리스트

🏗️ Phase 1 — 렉서 (Lexer)

[ ] 모든 토큰 타입 정의 완료
    [ ] 키워드 (if, for, def, return, while, class ...)
    [ ] 연산자 (=, ==, !=, =, +, -, , /, %, *)
    [ ] 구분자 ((), [], {}, :, ,, .)
    [ ] 리터럴 (정수, 실수, 문자열, bool, None)
    [ ] 식별자 (변수명, 함수명)
    [ ] 인덴트 / 디덴트 처리

[ ] 에러 처리
    [ ] 미지원 문자 → LexError 발생
    [ ] 미종결 문자열 → LexError 발생
    [ ] 에러 위치 (line:col) 보고

[ ] 테스트
    [ ] 빈 입력 처리
    [ ] 유니코드 문자열 처리
    [ ] 멀티라인 문자열 처리
    [ ] 주석 (#) 무시 확인

🌳 Phase 2 — 파서 (Parser)

[ ] AST 노드 타입 완비
    [ ] Program, Block
    [ ] AssignStmt, AugAssignStmt (+=, -=...)
    [ ] IfStmt, ElifClause, ElseClause
    [ ] ForStmt, WhileStmt, BreakStmt, ContinueStmt
    [ ] FunctionDef, ReturnStmt
    [ ] ClassDef
    [ ] ExprStmt, BinaryExpr, UnaryExpr
    [ ] CallExpr, IndexExpr, MemberExpr
    [ ] ListExpr, DictExpr, TupleExpr
    [ ] ImportStmt

[ ] 연산자 우선순위 정확성
    [ ] 산술 > 비교 > 논리 순서 검증
    [ ] 단항 연산자 (-, not) 처리
    [ ] 괄호 그룹핑

[ ] 에러 복구
    [ ] 구문 오류 위치 정확히 보고
    [ ] 예상 토큰 vs 실제 토큰 메시지

⚙️ Phase 3 — IR 생성 (IR Generation)

[ ] IR 명령셋 완비
    [ ] LOAD_CONST, LOAD_VAR, STORE_VAR
    [ ] BINARY_OP, UNARY_OP
    [ ] CALL, RETURN
    [ ] JUMP, JUMP_IF_FALSE, JUMP_IF_TRUE
    [ ] MAKE_LIST, MAKE_DICT, MAKE_TUPLE
    [ ] GET_ITEM, SET_ITEM
    [ ] LOAD_ATTR, STORE_ATTR

[ ] 스코프 관리
    [ ] 전역 스코프
    [ ] 함수 로컬 스코프
    [ ] 클로저 / 자유 변수 캡처
    [ ] 내포 함수 (nested function)

[ ] 루프 최적화                    ← ⚠️ 현재 이슈!
    [ ] range() 인라인 전개 → 런타임 이터레이터 전환
    [ ] 루프 변수 초기화 보장
    [ ] break / continue 점프 주소 정확성

[ ] 누적 변수 처리                 ← ⚠️ NaN 이슈!
    [ ] 루프 전 초기값 명시적 LOAD
    [ ] PHI 노드 or SSA 올바른 처리
    [ ] undefined 참조 사전 차단

🚀 Phase 4 — 실행 엔진 (Executor / VM)

[ ] 기본 실행
    [ ] 모든 IR 명령 실행 가능
    [ ] 콜스택 정상 동작 (재귀 포함)
    [ ] 스택 오버플로우 감지

[ ] 내장 함수 (Builtins)
    [ ] print(), input()
    [ ] range(), len(), type()
    [ ] int(), float(), str(), bool()
    [ ] list(), dict(), tuple()
    [ ] append(), extend(), pop()
    [ ] sorted(), reversed(), enumerate()
    [ ] map(), filter()
    [ ] min(), max(), sum(), abs()

[ ] 타입 시스템
    [ ] 동적 타입 처리 (int + float = float)
    [ ] None 타입 비교
    [ ] is / is not 연산자
    [ ] in / not in 연산자

[ ] 예외 처리
    [ ] try / except / finally
    [ ] raise 문
    [ ] 내장 예외 타입 (TypeError, ValueError...)
