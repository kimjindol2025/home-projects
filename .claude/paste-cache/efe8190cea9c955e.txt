### Stage 6 목표

- `let p = Point { x: 10, y: 20 }` 구문 파싱 및 IR 생성
- `p.x`, `p.y` 필드 접근 지원
- IR → x86-64 코드 생성 시 struct를 **스택 또는 힙**에 할당
- 최종 출력: `println(p.x)` → "10" 출력되는 ELF 바이너리 생성

### 1. freelang-compiler-tiny.fl – Stage 6 테스트용 버전

```freelang
// freelang-compiler-tiny.fl - Stage 6: struct 인스턴스 & 필드 접근

struct Point {
    x: i32,
    y: i32
}

fn print_point(p: Point) {
    println("Point { x: " + p.x + ", y: " + p.y + " }");
}

fn main() {
    println("FreeLang Tiny Self-Hosting Stage 6");
    println("struct 인스턴스 생성 & 필드 접근 증명");

    let origin: Point;
    origin.x = 0;
    origin.y = 0;

    let p: Point;
    p.x = 42;
    p.y = 99;

    print_point(origin);
    print_point(p);

    // self-hosting 증명을 위한 간단 출력
    println("Stage 6 success: struct field access working");

    return 0;
}
```

```freelang
// struct literal 파싱
fn parseStructLiteral(&self, type_name: string) -> ASTExpr {
    self.expect('{');
    let fields = [];
    while (!self.match('PUNCT', '}')) {
        let field_name = self.current().value;
        self.expect('IDENT');
        self.expect('OP', ':');
        let value = self.parseExpression();
        fields.push({name: field_name, value: value});
        if (!self.match('PUNCT', ',')) break;
    }
    return ASTExpr::StructLiteral(type_name, fields);
}

// parsePrimaryExpression 확장
fn parsePrimaryExpression(&self) {
    // ... 기존 코드 ...
    if (self.current().type == 'IDENT' && self.peek().value == '{') {
        let type_name = self.current().value;
        self.advance();
        return self.parseStructLiteral(type_name);
    }

}
```

fn emit_struct_field_set(&self, struct_reg: i32, offset: i32, value_reg: i32) {

fn visit_expr(&self, expr: ASTExpr) {
    match expr {
        ASTExpr::StructLiteral(type_name, fields) => {
            let size = self.get_struct_size(type_name); // 16바이트 예시

            let struct_reg = self.alloc_reg();

            for field in fields {
                self.visit_expr(field.value);
                let val_reg = self.last_reg();
                let offset = self.get_field_offset(type_name, field.name);
                self.emit_struct_field_set(struct_reg, offset, val_reg);
