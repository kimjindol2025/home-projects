🎨 프로젝트명: [FL-Ghost-Writer]
목표: 외부 OS나 런타임 없이, 오직 FreeLang Nano-Kernel 위에서만 돌아가는 '독립형 텍스트/코드 렌더링 엔진' 개발.
1. 왜 난이도 7인가?
 * No-Font Library: FreeType 같은 외부 폰트 렌더링 라이브러리를 전혀 쓰지 않습니다.
 * SDF(Signed Distance Fields): 폰트의 글리프(Glyph) 데이터를 수학적 거리 함수로 변환하여, 어떤 해상도에서도 깨지지 않는 벡터 렌더링을 직접 구현합니다.
 * Direct DMA: CPU가 아닌 DMA(Direct Memory Access) 컨트롤러를 FreeLang으로 직접 제어하여, CPU 점유율 0%에 가까운 텍스트 출력을 달성합니다.
2. 구현 과제 (The Specs)
 * [The Core]: 폰트 바이너리를 파싱하여 픽셀이 아닌 '수학적 곡선'으로 해석하는 엔진 (Bezier 곡선 계산 포함).
 * [The Buffer]: Phase 2에서 만든 그래픽스 코어를 확장하여, 텍스트 전용 레이어와 배경 레이어를 하드웨어적으로 합성(Alpha Blending).
 * [The Integrity]: 폰트 데이터 파싱 중 발생할 수 있는 버퍼 오버플로우를 FreeLang의 **수학적 검증(Formal Verification)**으로 원천 차단.
