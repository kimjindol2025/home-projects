왜 지금 바로 codegen 가면 위험하냐?

현재 상태:

AST → (TypeScript 내부 구조) → Codegen

문제는
IR이 명문화되어 있지 않으면

codegen.fl = TypeScript 내부 구조 복제판

이 된다.

그럼 self-hosting은 되지만
메타 플랫폼은 죽는다.

그건 “TS를 FL로 옮긴 것”일 뿐이다.


---

🔥 올바른 순서

1️⃣ IR 1.0 명세 작성 (문서 수준으로 고정)

반드시 정의:

Value 모델

Instruction 집합

Control Flow 모델 (block, branch)

Function ABI

Memory layout

Type lowering 규칙


이게 없으면 codegen은 모래 위에 집이다.


---

2️⃣ ir_gen.fl 먼저 작성

AST → Free IR

이 단계가 진짜 핵심이다.

여기서:

의미론 고정

타입 해석 고정

호출 규약 고정


이게 완성되면
TS 컴파일러는 단순 IR 실행기 역할로 축소된다.


---

3️⃣ 그 다음 codegen.fl

IR → x86 / LLVM IR / WASM

이때는 코드 생성이 단순 매핑이 된다.


---

🎯 Self-Hosting의 진짜 기준

진짜 self-hosting은 이거다:

FL source
   ↓
FL frontend
   ↓
FL IR
   ↓
FL codegen
   ↓
binary

그리고

> TS는 bootstrap 전용으로 격리
