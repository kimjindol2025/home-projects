🔧 API 기초
기본 정보
베이스 URL: https://gogs.dclub.kr/api/v1
인증: Token 기반 (Authorization 헤더)
응답 형식: JSON
API 버전 확인
curl https://gogs.dclub.kr/api/v1/version
🔐 인증 방법
1. Token 인증 (권장)
# 헤더에 토큰 추가
GOGS_TOKEN="8c8b66918576eda643c80ab30da43c8d794bcc84"
curl -H "Authorization: token $GOGS_TOKEN" \
  https://gogs.dclub.kr/api/v1/user
현재 사용 가능한 토큰:

8c8b66918576eda643c80ab30da43c8d794bcc84
2. 기본 인증 (Basic Auth)
curl -u username:password \
  https://gogs.dclub.kr/api/v1/user
3. 토큰 생성 방법
https://gogs.dclub.kr 로그인
설정 → 애플리케이션 → 새 토큰
토큰명 입력 및 범위 선택 (all 권장)
생성 후 토큰 복사
주의: 토큰은 재표시되지 않으니 안전하게 보관하세요!

📦 저장소 관리
1. 저장소 생성
# 필수 필드만
curl -X POST https://gogs.dclub.kr/api/v1/user/repos \
  -H "Authorization: token TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-repo"
  }'

# 모든 옵션 포함
curl -X POST https://gogs.dclub.kr/api/v1/user/repos \
  -H "Authorization: token TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "my-repo",
    "description": "My awesome repository",
    "private": false,
    "default_branch": "master",
    "gitignores": "Go",
    "license": "MIT",
    "readme": "Default"
  }'
주의: ⚠️ auto_init: true 파라미터 사용 금지 (500 에러 발생)

2. 저장소 목록 조회
# 자신의 저장소
curl -H "Authorization: token TOKEN" \
  https://gogs.dclub.kr/api/v1/user/repos

# 특정 사용자의 저장소
curl https://gogs.dclub.kr/api/v1/users/username/repos

# 저장소 검색
curl -H "Authorization: token TOKEN" \
  'https://gogs.dclub.kr/api/v1/repos/search?q=keyword&limit=10'
3. 저장소 상세 정보
curl https://gogs.dclub.kr/api/v1/repos/owner/repo
4. 저장소 수정
curl -X PATCH https://gogs.dclub.kr/api/v1/repos/owner/repo \
  -H "Authorization: token TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "new-name",
    "description": "New description",
    "private": false
  }'
5. 저장소 삭제
curl -X DELETE https://gogs.dclub.kr/api/v1/repos/owner/repo \
  -H "Authorization: token TOKEN"
6. Fork 생성
curl -X POST https://gogs.dclub.kr/api/v1/repos/owner/repo/forks \
  -H "Authorization: token TOKEN"

📚 실제 사용 예제
bash 스크립트: 저장소 자동 생성
#!/bin/bash

GOGS_TOKEN="your_token_here"
REPO_NAMES=("repo1" "repo2" "repo3")

for repo in "${REPO_NAMES[@]}"; do
  curl -X POST https://gogs.dclub.kr/api/v1/user/repos \
    -H "Authorization: token $GOGS_TOKEN" \
    -H "Content-Type: application/json" \
    -d "{
      \"name\": \"$repo\",
      \"description\": \"Auto-created repository\",
      \"private\": false
    }"
  echo "Created: $repo"
done
Node.js: 저장소 생성
const axios = require('axios');

const GOGS_TOKEN = 'your_token_here';
const GOGS_API = 'https://gogs.dclub.kr/api/v1';

async function createRepo(repoName, description = '') {
  try {
    const response = await axios.post(
      `${GOGS_API}/user/repos`,
      {
        name: repoName,
        description: description,
        private: false
      },
      {
        headers: {
          'Authorization': `token ${GOGS_TOKEN}`,
          'Content-Type': 'application/json'
        }
      }
    );
    console.log('✅ 저장소 생성:', response.data.html_url);
    return response.data;
  } catch (error) {
    console.error('❌ 오류:', error.response?.data?.message || error.message);
  }
}

createRepo('my-awesome-repo', 'My repository description');
Python: 저장소 검색
import requests
import json

GOGS_TOKEN = 'your_token_here'
GOGS_API = 'https://gogs.dclub.kr/api/v1'

def search_repos(keyword, limit=10):
    response = requests.get(
        f'{GOGS_API}/repos/search',
        params={'q': keyword, 'limit': limit},
        headers={'Authorization': f'token {GOGS_TOKEN}'}
    )

    if response.status_code == 200:
        data = response.json()
        for repo in data.get('data', []):
            print(f"📦 {repo['full_name']} - {repo['description']}")
    else:
        print(f"❌ 오류: {response.json()}")

search_repos('freelang')
