이름하여 **"Bigwash Native Shell (BNS)"**입니다.
🚀 미션: Bigwash Native Shell (BNS) 구현
안드로이드 앱이지만, 내부는 님의 FreeLang v6와 Termux 환경을 직접 제어하는 전용 쉘입니다. 일반적인 앱 개발 방식이 아닌, 시스템 프로그래밍 관점으로 접근합니다.
1. 핵심 아키텍처 (Hybrid Layer)
 * Layer 1 (Core): Termux 내부에서 돌아가는 FreeLang v6 런타임.
 * Layer 2 (Bridge): 시스템 시스콜과 Gogs API 데이터를 JSON 스트림으로 변환하는 Unix Domain Socket.
 * Layer 3 (UI): 외부 라이브러리(React/Flutter) 없이, 오직 Vanilla JS + CSS Grid로만 구성된 초경량 관제 화면.
2. 앱의 특수 기능 (Feature)
 * Live 'Gogs' Feed: 커밋이 발생할 때마다 폰에 '기록 증명' 알림이 뜨고, 터치하면 해당 코드의 Diff를 즉시 확인.
 * Zero-Copy Viewer: 님이 만든 Zero-Copy-DB의 데이터 구조를 메모리 맵(mmap) 방식으로 읽어와 지연 시간 없이 차트로 시각화.
 * Emergency Kill-Switch: 서버 부하가 높거나 외부 의존성이 감지되면 폰에서 즉시 프로세스 강제 종료.
🛠️ 바로 시작할 수 있는 구현 단계 (Phase 1)
지금 Claude Code와 함께 **'최소 기능 제품(MVP)'**을 설계해 볼까요?
 * WebView 기반 껍데기 생성: 안드로이드 네이티브 코드는 최소화하고, 님의 서버 데이터를 뿌려줄 고성능 웹뷰를 설정합니다.
 * FreeLang API 서버 구축: Termux 내에서 현재 프로젝트 상태(PLAN.md, MAP.md)를 읽어서 웹뷰로 쏴주는 초경량 서버를 작성합니다.
 * UI 테마 적용: 님의 철학이 느껴지는 Terminal Black & Matrix Green 테마로 "기록이 증명이다" 문구가 상단에 흐르게 만듭니다.
🎯 이 미션이 재미있는 이유
이것은 단순한 '앱'이 아니라, 님이 만든 **FreeLang 언어와 DB가 실제로 유저 인터페이스(UI)를 제어하는 '독립 플랫폼'**의 첫걸음이기 때문입니다.
