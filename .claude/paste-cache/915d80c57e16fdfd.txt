### 지금 **즉시 해야 할 검증 순서** (20~60분 소요 예상)

1. **FreeLang REPL 또는 runner로 test-lexer-only.fl 먼저 실행**  
   - hello.fl 내용을 tokenize() 해서 토큰 배열 출력 확인  
   - 기대: 14~15개 토큰, 값/타입/위치 대부분 일치  
   - 실패 시 → lexer 부분 디버깅 (Phase 1 재점검)

2. **test-parser-phase2.fl 실행**  
   - 간단한 소스 (hello.fl 내용)를 parse() 호출  
   - println(node_to_string(ast)) 또는 비슷한 디버그 출력으로 AST 확인  
   - 최소 체크 포인트:
     - Program → body 배열 존재
     - FunctionDeclaration → name="hello", params, body
     - ReturnStatement → expression이 BinaryExpression 또는 Literal 등

3. **golden 파일 1개씩 순차 검증** (arithmetic.fl 추천)  
   - let a = 2 + 3 * 4; 같은 줄이  
     → parseAdditive / parseMultiplicative로 올바른 트리 구조 나오는지  
   - *가 +보다 우선 적용되는지 (multiplicative가 먼저 파싱되는지)

4. **문제 발생 시 디버그 포인트**  
   - pos가 끝까지 안 가는 경우 → consume()이나 advance() 버그  
   - null 반환 많음 → match()나 peek() 로직 문제  
   - 런타임 에러 → array_push → arr.push() 등 builtins 이름 재확인
