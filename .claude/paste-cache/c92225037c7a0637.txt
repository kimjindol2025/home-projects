  🎯 구현 현황

  Phase 7: LLVM IR Backend (550줄 + 20 테스트) ✅

  - 아키텍처 독립 중간 표현 생성
  - 가상 레지스터 (%0, %1, ...) 기반 SSA 형식
  - 산술(add, sub, mul, sdiv, srem), 비교(icmp),
  제어흐름(br, ret) 명령어
  - 함수 정의/호출 지원

  Phase 8: Compiler Driver (173줄 + 15 테스트) ✅

  - 플랫폼별 어셈블러/링커 자동 매핑
  - Target enum: x86_64, riscv64, arm64
  - 메서드: getAssembler(), getLinker(), assemble(),
  link(), compileAndLink()
  - 각 아키텍처별 정확한 컴파일러 플래그 생성

  Phase 9: Stdlib Generator (212줄 + 10 테스트) ✅

  - Linux syscall 기반 표준 라이브러리 코드 생성
  - std_print(): write syscall (stdout)
  - std_exit(): exit syscall
  - std_itoa(): 정수→문자열 변환
  - 아키텍처별 syscall 번호 자동 변환

  🚀 사용 방법

  # LLVM IR 생성
  ./zig-out/bin/zig-compiler --emit-llvm test.zig -o
  test.ll

  # 어셈블리 생성
  ./zig-out/bin/zig-compiler --emit-x86-64 test.zig -o
  test.asm

  # 컴파일 & 링크
  ./zig-out/bin/zig-compiler --emit-x86-64 --compile
  --target x86_64 test.zig -o test

  # 표준 라이브러리 포함
  ./zig-out/bin/zig-compiler --emit-riscv --stdlib
  test.zig -o test.s
