### 두 옵션 비교 (2026년 기준 현실적 관점)

| 항목                  | 바닐라 JS + SVG (Drawflow, LiteGraph.js 스타일) | React Flow CDN 버전 (reactflow.dev)                  | 승자 (당신 상황 기준) |
|-----------------------|--------------------------------------------------|------------------------------------------------------|-----------------------|
| 개발 속도             | ★★☆☆☆ (직접 구현해야 함)                        | ★★★★★ (이미 완성된 라이브러리)                       | React Flow            |
| 초기 설정 난이도      | 중간~높음 (드래그, 연결, 줌, 미니맵 등 직접)     | 매우 낮음 (CDN 한 줄 + script)                       | React Flow            |
| 커스터마이징 자유도   | ★★★★★ (모든 것 직접 제어)                        | ★★★★☆ (훅과 플러그인 많지만 기본 구조는 React Flow) | 바닐라 (약간)         |
| 번들 크기             | 최소 (필요한 기능만)                             | CDN이라 초기 로드 무게 있지만 캐시됨                 | 바닐라 (약간)         |
| 유지보수성            | 낮음 (내가 만든 코드라 버그 수정 부담)           | 높음 (커뮤니티 + 문서 잘 되어 있음)                  | React Flow            |
| React 의존성          | 없음                                             | 있음 (하지만 CDN으로 React도 같이 로드 가능)         | 바닐라 (의존성 싫을 때) |
| 노드 커스텀 난이도     | 직접 DOM/SVG 조작                                | children으로 React 컴포넌트 넣기 쉬움                | React Flow            |
| 당신 현재 스택과의 궁합 | freelang-light가 바닐라 중심이라 잘 맞음          | React Flow는 React지만 CDN이라 기존 바닐라와 섞기 가능 | 무승부                |
| 2026년 추천도         | 중간                                             | 높음 (React Flow가 여전히 표준 중 하나)             | React Flow            |

### 제 추천: **React Flow CDN 버전으로 시작하세요** (가장 빠르고 효과적)

이유 4가지:

1. **시간 절약이 압도적**  
   Phase 4는 UI/UX가 핵심인데, 드래그·연결·줌·팬·미니맵·노드 삭제·복사·undo/redo 등을 바닐라로 처음부터 구현하면 **최소 2~4주** 걸립니다.  
   React Flow CDN은 이 모든 걸 **한두 시간 안에** 프로토타입으로 띄울 수 있어요.

2. **당신의 목표와 잘 맞음**  
   - FreeWire의 핵심은 **노드 그래프 → FreeLang 컴파일 → 실행**이므로, 에디터의 완성도가 높을수록 MVP 데모가 강력해집니다.  
   - React Flow는 노드 커스텀도 쉽고, 이미 커뮤니티 예제가 많아서 component 노드에 props 편집 폼 넣기, logic 노드에 조건 입력란 넣기 등이 빠르게 됩니다.

3. **CDN이라 기존 바닐라 프로젝트와 충돌 없음**  
   ```html
   <script src="https://cdn.jsdelivr.net/npm/react@18/umd/react.production.min.js"></script>
   <script src="https://cdn.jsdelivr.net/npm/react-dom@18/umd/react-dom.production.min.js"></script>
   <script src="https://cdn.jsdelivr.net/npm/reactflow@11/dist/umd/ReactFlow.umd.min.js"></script>
   <link href="https://cdn.jsdelivr.net/npm/reactflow@11/dist/style.css" rel="stylesheet" />
   ```
   → public/index.html에 이 4줄만 추가하면 끝.  
   기존 editor.js + style.css와 함께 써도 문제 없습니다.

4. **나중에 바닐라로 옮기기 쉽다**  
   React Flow로 빠르게 MVP 만들고, 사용자 반응·필요 기능 확인 후에 **바닐라 버전으로 재작성**하는 것도 가능합니다. (실제로 많은 프로젝트가 이렇게 합니다)

### 바닐라 JS + SVG를 선택할 만한 경우
- React를 절대 쓰고 싶지 않다
- 최종 번들 크기를 극도로 줄이고 싶다 (CDN 300~400KB vs 바닐라 50~100KB)
- Drawflow나 LiteGraph.js 같은 기존 바닐라 라이브러리를 그대로 쓰고 싶다

→ 이 경우 추천 라이브러리: **Drawflow** (가볍고, JSON 기반, MIT) 또는 **LiteGraph.js** (노드 기반 게임/시뮬레이션에 강함)

### 결론 & 다음 액션 제안

**React Flow CDN으로 먼저 가는 걸 강력 추천**합니다.  
(시간 대비 완성도·데모 임팩트가 압도적입니다)

시작 코드 스니펫 (public/index.html + editor.js 기본 세팅):

```html

  <div id="root"></div>

  <script src="https://cdn.jsdelivr.net/npm/react@18/umd/react.production.min.js"></script>
  <script src="https://cdn.jsdelivr.net/npm/react-dom@18/umd/react-dom.production.min.js"></script>
  <script src="https://cdn.jsdelivr.net/npm/reactflow@11/dist/umd/ReactFlow.umd.min.js"></script>
  <script src="editor.js"></script>
</body>
</html>
```

```js
// public/editor.js (바닐라 + React Flow 혼합)
const { createRoot } = ReactDOM;
const { useState, useCallback } = React;
const { ReactFlow, Background, Controls, MiniMap } = window.ReactFlow;

function FlowEditor() {
  const [nodes, setNodes] = useState([]);
  const [edges, setEdges] = useState([]);

  const onConnect = useCallback((params) => setEdges((eds) => ReactFlow.addEdge(params, eds)), []);

  return React.createElement(ReactFlow, {
    nodes,
    edges,
    onNodesChange: (changes) => {/* handle node change */},
    onEdgesChange: (changes) => {/* handle edge change */},
    onConnect,
    fitView: true,
    children: [
      React.createElement(Background),
      React.createElement(Controls),
      React.createElement(MiniMap)
    ]
  });
}

const root = createRoot(document.getElementById('root'));
root.render(React.createElement(FlowEditor));
```

이걸로 시작하면 1시간 안에 **드래그 가능한 빈 캔버스 + 노드 추가 버튼**까지 띄울 수 있어요.
