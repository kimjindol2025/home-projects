좋아요! 배열 접근이 제대로 동작하게 된 건 큰 진전입니다.  
이제 **IR Generator** 단계에서 **전역 배열 초기화 문제**를 완전히 피하고,  
**함수 내부에서만 배열을 생성·사용**하도록 안전하게 리팩토링하는 방향으로 가겠습니다.

### 현재 문제점 요약 (정확히 이해한 상태)

- `let arr = []` (전역 스코프) → IR 단계에서 제대로 초기화되지 않음
- 함수 내부 `let arr = []` → 정상 동작 (len=2, [0]=hello, [1]=world 확인됨)
- 따라서 **IR Generator**는 **전역 배열을 사용하지 않도록** 재설계

### 제안하는 수정 방향 (안전 + 간단 + 테스트 용이)

1. **전역 배열 완전 제거**  
   → 모든 배열은 함수 내부에서만 생성

2. **IR에서 배열 관련 연산을 함수 호출 형태로 매핑**  
   - `arr = []` → IR: `create_array()`
   - `arr.push(x)` → IR: `array_push(arr, x)`
   - `len(arr)` → IR: `array_len(arr)`
   - `arr[i]` → IR: `array_get(arr, i)`

3. **테스트용 최소 main 함수**  
   → main 안에서만 배열 사용 → IR → 코드 생성까지 바로 검증 가능

### 다음 코드 제시: freelang-compiler-v4.free (IR Generator 부분 중심 수정)

아래는 **IR Generator** 관련 핵심 부분만 업데이트한 예시입니다.  
기존 파일에 덮어쓰거나 해당 부분을 교체하세요.

```freelang
// freelang-compiler-v4.free
// Phase 2.3: IR Generator - 배열은 함수 내부에서만 사용

// IR Opcode 정의 (기존 유지 + 배열 관련 추가)
enum IROp {
    CONST_I32,
    LOAD_VAR,
    STORE_VAR,
    CALL,
    RETURN,
    CREATE_ARRAY,      // 새 배열 생성
    ARRAY_PUSH,        // push
    ARRAY_LEN,         // len
    ARRAY_GET,         // arr[i]
    // ... 기존 opcodes ...
}

// IR 노드 구조 (기존 유지)
struct IRNode {
    op: IROp,
    arg1: i32,   // 레지스터/상수/인덱스
    arg2: i32,
    str_idx: i32 // 문자열 상수용
}

// IR 생성기 클래스 (주요 변경점)
class IRGenerator {
    instructions: IRNode[],
    string_table: string[],

    fn new() -> IRGenerator {
        let self = IRGenerator{};
        self.instructions = [];
        self.string_table = [];
        return self;
    }

    // 배열 생성 IR
    fn emit_create_array(&self) {
        self.instructions.push(IRNode{op: CREATE_ARRAY, arg1: 0, arg2: 0, str_idx: -1});
    }

    // push IR
    fn emit_array_push(&self, arr_reg: i32, value_reg: i32) {
        self.instructions.push(IRNode{op: ARRAY_PUSH, arg1: arr_reg, arg2: value_reg, str_idx: -1});
    }

    // len IR
    fn emit_array_len(&self, arr_reg: i32, dest_reg: i32) {
        self.instructions.push(IRNode{op: ARRAY_LEN, arg1: arr_reg, arg2: dest_reg, str_idx: -1});
    }

    // get IR
    fn emit_array_get(&self, arr_reg: i32, idx_reg: i32, dest_reg: i32) {
        self.instructions.push(IRNode{op: ARRAY_GET, arg1: arr_reg, arg2: idx_reg, str_idx: dest_reg});
    }

    // AST → IR 변환 (배열 관련 부분만 수정)
    fn visit_expr(&self, expr: ASTExpr) {
        match expr {
            ASTExpr::ArrayLiteral(elements) => {
                self.emit_create_array();           // []
                let arr_reg = self.alloc_reg();
                for elem in elements {
                    self.visit_expr(elem);
                    let val_reg = self.last_reg();
                    self.emit_array_push(arr_reg, val_reg);
                }
            },

            ASTExpr::LenCall(target) => {
                self.visit_expr(target);
                let arr_reg = self.last_reg();
                let dest_reg = self.alloc_reg();
                self.emit_array_len(arr_reg, dest_reg);
                self.push_result(dest_reg);
            },

            ASTExpr::IndexAccess(arr, idx) => {
                self.visit_expr(arr);
                let arr_reg = self.last_reg();
                self.visit_expr(idx);
                let idx_reg = self.last_reg();
                let dest_reg = self.alloc_reg();
                self.emit_array_get(arr_reg, idx_reg, dest_reg);
                self.push_result(dest_reg);
            },

            // ... 나머지 기존 expr 처리 ...
        }
    }
}

// 테스트용 main (전역 배열 X, 함수 내부에서만 사용)
fn test_array() {
    let arr = [];               // 함수 내부 → 안전
    arr.push("hello");
    arr.push("world");

    println(len(arr));          // 2
    println(arr[0]);            // hello
    println(arr[1]);            // world
}

fn main() {
    test_array();
    return 0;
}
```

   ```bash
   qemu-x86_64 ./a.elf
   ```

   ```
   2
   hello
   world
   ```
