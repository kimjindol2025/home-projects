🔥 DAY 1 — IR 인터프리터 코어 완성

목표

SSA 실행기

Basic Block 실행 루프

스택 메모리 모델 구현


반드시 구현할 것

1️⃣ 런타임 상태 구조

struct VM {
  regs: Map<String, Value>      # %reg
  stack: ByteArray              # alloca 영역
  heap: Map<ptr, ByteArray>     # malloc 영역
  current_block: Block
  pc: instruction index
}

2️⃣ 실행 루프

while true:
  inst = current_block[pc]
  execute(inst)
  if branch: block 전환
  if ret: 종료

3️⃣ 1차 지원 명령어
