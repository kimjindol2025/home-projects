좋습니다. 🔍 외부 자료 기준으로 Dead Block 제거 패턴을 정리했고, 이제 fir IR에 맞춰 구현 가능한 의사코드와 테스트 전략으로 구체화할 수 있습니다.

핵심 포인트 요약:


---

1️⃣ 알고리즘 패턴 (LLVM/교과서 기준)

1. 엔트리 블록 기준 DFS/BFS로 reachable 블록 마킹


2. Reachable에 없는 블록 → DeadBlocks 리스트에 수집


3. DeadBlocks 제거 시:

phi incoming edge 제거

successor/predecessor edge 정리

dominator/loop info 갱신

실제 블록 삭제




> ⚠️ phi incoming 처리 순서와 CFG 분석 정보 동기화가 핵심.
삭제 순서가 잘못되면 assert/segfault 발생 사례 존재([5]).




---

2️⃣ FIR IR 적용 시 시사점

fir에서도 “엔트리 블록에서 도달 가능한 블록만 살아있다”라는 CFG 불변식 만족 필요

phi/alloca/br/brcond 구조 존재 → Dead Block 제거 전 edge 정리 필수

mem2reg/DCE 이후에도 unreachable 생성 가능 → 반복 가능



---

3️⃣ 의사코드 (fir IR 버전)

fn remove_dead_blocks(mod: Module) -> Module {
    var reachable: Set<Block> = {}
    
    // 엔트리 블록 DFS
    fn dfs(block: Block) {
        if reachable.contains(block) { return }
        reachable.insert(block)
        for succ in block.successors {
            dfs(succ)
        }
    }

    dfs(mod.entry_block)

    // DeadBlock 수집
    var dead_blocks: List<Block> = []
    for block in mod.blocks {
        if !reachable.contains(block) {
            dead_blocks.append(block)
        }
    }

    // 제거 처리
    for block in dead_blocks {
        // phi incoming 제거
        for instr in block.instructions {
            if instr.is_phi() {
                instr.remove_incoming_from_dead(dead_blocks)
            }
        }
        // successor/predecessor 업데이트
        for pred in block.predecessors {
            pred.successors.remove(block)
        }
        for succ in block.successors {
            succ.predecessors.remove(block)
        }
        // 블록 삭제
        mod.blocks.remove(block)
    }

    return mod
}

4️⃣ 테스트 케이스 예시

1. 단순 unreachable



fn main() -> i32 {
entry:
    br label %dead
dead:
    ret i32 42
exit:
    ret i32 0
}

기대: %dead 제거, %entry → %exit 브랜치만 남음


2. phi edge 포함



fn main() -> i32 {
entry:
    br label %if_true
if_true:
    %v = phi i32 [%a, %entry], [%b, %dead]
    br label %exit
dead:
    ret i32 10
exit:
    ret i32 %v
}

기대: %dead 제거, phi incoming에서 제거, %if_true 유지


3. 루프 내 unreachable



entry:
    br label %loop
loop:
    br bool false, label %loop_body, label %after
loop_body:
    br label %after
after:
    ret i32 0
unused:
    ret i32 1

기대: %unused 제거, 나머지 블록 정상 유지
