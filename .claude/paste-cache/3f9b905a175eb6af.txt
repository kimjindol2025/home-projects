좋아요! Phase 2.3 (IR Generator)이 안전하게 완료되었으니,  
**Phase 3: Code Generation**을 시작할 차례입니다.

현재 목표  
- IR 명령어 (`CREATE_ARRAY`, `ARRAY_PUSH`, `ARRAY_GET`, `ARRAY_LEN` 등)를  
  **x86-64 머신 코드** + **ELF 실행 파일**로 변환  
- 배열은 **런타임 헬퍼 함수**로 구현 (동적 메모리 할당 + 간단한 벡터 구조)  
- 최소한의 ELF 바이너리가 생성되어 **실행 시 "hello world" 배열 출력** 가능

### Phase 3 시작을 위한 최적 코드 구조

1. **런타임 헬퍼 함수** (x86-64 어셈블리 형태로 미리 정의)  
   → 배열 관리용 (create, push, get, len)

2. **IR → x86-64 코드 생성기** (FreeLang으로 작성)

3. **ELF 헤더 + 코드 섹션 조합** → 실행 파일 출력

아래는 **freelang-compiler-v4-safe.free** 파일에 **Phase 3 부분**을 추가하는 형태입니다.  
(기존 파일 끝부분에 붙여넣기 추천)

```freelang
// ================================================
// Phase 3: Code Generation (x86-64 + ELF)
// ================================================

// 1. 런타임 헬퍼 함수들 (x86-64 어셈블리 문자열로 미리 정의)
//    → 실제로는 나중에 바이너리로 인라인되지만, 지금은 시뮬레이션용
let runtime_helpers = [
    // array_create() → rax = 새 배열 포인터
    "array_create:\n" +
    "  mov rdi, 16          ; 초기 용량 16\n" +
    "  mov rax, 12          ; brk syscall\n" +
    "  syscall\n" +
    "  mov rbx, rax         ; 저장\n" +
    "  add rdi, 16*8        ; 용량 × 8바이트\n" +
    "  mov rax, 12\n" +
    "  syscall\n" +
    "  mov [rbx], rdi       ; capacity\n" +
    "  mov [rbx+8], 0       ; length\n" +
    "  mov rax, rbx\n" +
    "  ret\n",

    // array_push(arr:rdi, val:rsi)
    "array_push:\n" +
    "  mov rax, [rdi+8]     ; length\n" +
    "  cmp rax, [rdi]       ; vs capacity\n" +
    "  jl .no_realloc\n" +
    "  ; 재할당 로직 생략 (간단히)\n" +
    ".no_realloc:\n" +
    "  mov rcx, [rdi+8]\n" +
    "  shl rcx, 3           ; ×8\n" +
    "  add rcx, rdi\n" +
    "  add rcx, 16          ; 데이터 시작\n" +
    "  mov [rcx], rsi\n" +
    "  inc qword [rdi+8]\n" +
    "  ret\n",

    // array_len(arr:rdi) → rax = length
    "array_len:\n" +
    "  mov rax, [rdi+8]\n" +
    "  ret\n",

    // array_get(arr:rdi, idx:rsi) → rax = 값
    "array_get:\n" +
    "  mov rcx, rsi\n" +
    "  shl rcx, 3\n" +
    "  add rcx, rdi\n" +
    "  add rcx, 16\n" +
    "  mov rax, [rcx]\n" +
    "  ret\n"
];

// 2. ELF 생성기 (간단 버전)
fn generate_elf(ir_instructions: IRNode[]) -> bytes {
    // ELF 헤더 (64바이트) + Program Header (56바이트) + 코드 섹션
    let elf = bytes_new(1024);  // 임시 버퍼

    // ELF Header 기본값 (x86-64 executable)
    elf_write(elf, 0, "\x7fELF\x02\x01\x01\x00\x00\x00\x00\x00\x00\x00\x00\x00");
    elf_write16(elf, 16, 2);     // e_type = ET_EXEC
    elf_write16(elf, 18, 0x3e);  // e_machine = EM_X86_64
    elf_write32(elf, 24, 1);     // e_version
    elf_write64(elf, 32, 0x400000); // e_entry
    elf_write64(elf, 40, 64);    // e_phoff
    elf_write16(elf, 48, 64);    // e_ehsize
    elf_write16(elf, 50, 56);    // e_phentsize
    elf_write16(elf, 52, 1);     // e_phnum

    // Program Header (PT_LOAD)
    elf_write32(elf, 64, 1);     // p_type = PT_LOAD
    elf_write32(elf, 68, 5);     // p_flags = R+X
    elf_write64(elf, 72, 0);     // p_offset
    elf_write64(elf, 80, 0x400000); // p_vaddr
    elf_write64(elf, 88, 0x400000); // p_paddr
    // p_filesz, p_memsz는 나중에 채움

    // 코드 섹션 시작 위치
    let code_offset = 120;
    let code_pos = code_offset;

    // 런타임 헬퍼 함수들 인라인
    for helper in runtime_helpers {
        elf_write_bytes(elf, code_pos, helper.as_bytes());
        code_pos += helper.length();
    }

    // IR → x86-64 변환 (핵심 부분)
    for instr in ir_instructions {
        match instr.op {
            CREATE_ARRAY => {
                // call array_create
                elf_write(code_pos, "\xe8");          // call rel32
                elf_write32(code_pos+1, array_create_offset - (code_pos + 5));
                code_pos += 5;
            }
            ARRAY_PUSH => {
                // mov rdi, arr_reg; mov rsi, val_reg; call array_push
                // (레지스터 할당 로직 생략 - 실제 구현 시 필요)
                elf_write(code_pos, "\xbf"); // mov rdi, imm32 (예시)
                code_pos += 5;
                elf_write(code_pos, "\xbe");
                code_pos += 5;
                elf_write(code_pos, "\xe8");
                elf_write32(code_pos+1, array_push_offset - (code_pos + 5));
                code_pos += 5;
            }
            // ARRAY_LEN, ARRAY_GET도 유사하게
            // ...
        }
    }

    // ELF 크기 최종 채움
    elf_write64(elf, 72+32, code_pos - code_offset); // p_filesz
    elf_write64(elf, 72+40, code_pos - code_offset); // p_memsz

    return elf_slice(0, code_pos);
}

// 테스트 main
fn main() {
    let ir = IRGenerator.new().generate_test_array();
    let binary = generate_elf(ir.instructions);
    write_file("test-compiler.elf", binary);
    println("ELF generated: test-compiler.elf");
    println("Size: " + binary.length());
    return 0;
}
```

### 적용 & 테스트 방법

1. **freelang-compiler-v4-safe.free** 파일 끝부분에 위 Phase 3 코드 붙여넣기

2. **self-compile 테스트**
   ```bash
   ./bin/fl run freelang-compiler-v4-safe.free
   # 또는 node full-e2e-compiler.js freelang-compiler-v4-safe.free
   ```

3. **생성된 ELF 확인**
   ```bash
   ls -l test-compiler.elf
   file test-compiler.elf          # ELF 64-bit executable 확인
   qemu-x86_64 ./test-compiler.elf # 실행 시도
   ```
