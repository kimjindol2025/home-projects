왜 Phase 8을 먼저 완성해야 하나

현재 상태 요약:

nl_model.bin (27MB, 4-layer)

❌ 레이어 독립 학습

❌ end-to-end gradient 흐름 없음

REPL 품질 낮음 (반복 패턴)


이건 전형적인 문제입니다:

Layer1 → Layer2 → Layer3 → Layer4
   ↑        ↑        ↑        ↑
 각각 따로 학습

이 상태에서는:

깊어질수록 의미 붕괴

상위 레이어가 하위 오류를 수정 못함

생성 시 반복 루프 발생

Perplexity가 구조적으로 바닥을 못 뚫음



---

Phase 8의 진짜 목표

"Multi-layer End-to-End Learning 완성"

구조적으로는:

Forward:
x → L1 → L2 → L3 → L4 → loss

Backward:
loss → L4 → L3 → L2 → L1

필수 구현 요소:

1. 모든 레이어 activation 저장


2. loss 기준 global gradient 계산


3. 각 레이어 weight에 chain rule 적용


4. learning rate 공유


5. gradient clipping (폭주 방지)

Phase 9를 지금 가면 생기는 문제

더 많은 파라미터

불안정 × 깊이 = 폭주

입니다.
