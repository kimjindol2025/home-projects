Kim님, DNS는 주권 세계의 **'지도'**입니다. 지도가 완성되면 그 위에서 안전하게 물자를 실어나를 **'수송 체계'**가 필요하죠. 이제 데이터 주권의 마지막 퍼즐, **[Project Sovereign-Mesh: The Dark-Fiber]**로 진입합니다.
이 미션은 기존 인터넷망(ISP)이 차단되거나 감시받는 상황에서도, 주권 기기들이 서로를 무선(Wi-Fi, Bluetooth, SDR)으로 연결하여 거대한 독자적 인트라넷을 형성하는 도전입니다.
🕸️ Mission: [Sovereign-Mesh]
목표: 중앙 게이트웨이 없이 기기 간(P2P) 직접 연결로 데이터를 전달하는 '물리적 독립 망' 구축.
1. [Challenge 16] 동적 라우팅 프로토콜 (Kinetic-Router)
기기들이 움직여도 연결이 끊기지 않아야 합니다.
 * 도전: **OLSR(Optimized Link State Routing)**을 커널 레벨에서 L0NN과 통합하여 구현하십시오.
 * 혁신: AI가 주변 기기들의 이동 패턴과 신호 세기를 학습하여, 데이터가 끊기지 않을 **'최적의 릴레이 노드'**를 0.5ms 내에 선택합니다.
 * 무관용 규칙: 노드 이탈 시 재라우팅(Re-routing) 지연 < 10ms.
2. [Challenge 17] 제로-트러스트 패킷 포워딩 (Ghost-Packet)
남의 데이터를 전달해주면서도 그 내용은 절대 볼 수 없어야 합니다.
 * 도전: 어니언 라우팅(Onion Routing) 기술을 L0 커널의 네트워크 스택에 직접 내장하십시오.
 * 전술: 각 노드는 패킷의 다음 목적지만 알 수 있으며, 전체 경로나 원본 데이터는 다중 암호화 레이어(Onion) 뒤에 숨겨집니다.
 * 무관용 규칙: 패킷 포워딩 오버헤드 < 0.1ms.
🏗️ Sovereign-Mesh 시스템 구조
| 계층 | 모듈명 | 핵심 기술 | 역할 |
|---|---|---|---|
| L3 | mesh_api.fl | Virtual Interface | 기존 앱들이 메쉬망을 일반 네트워크처럼 사용 |
| L2 | kinetic_route.fl | L0NN + OLSR | 움직이는 기기들 사이의 최적 경로 계산 |
| L1 | onion_tunnel.fl | Multi-layer Encryption | 경유 노드로부터 데이터 완벽 보호 |
| L0 | radio_hal.fl | SDR / Wi-Fi Direct | 물리적 무선 신호 제어 및 주파수 도약 |
📊 이번 미션의 무관용 규칙 (Unforgiving Rules)
 * Rule 1 (Zero-Infrastructure): 통신사 기지국이나 외부 AP 도움 없이 3대 이상의 기기가 100% 독립 통신 성공.
 * Rule 2 (Stealth-Mode): 외부 패킷 분석 시, 해당 트래픽이 '메쉬 데이터'임을 식별할 수 없도록 무작위 노이즈 패킷(Chaffing) 삽입.
 * Rule 3 (Latency-Bound): 3홉(Hop) 거쳐 전달 시 전체 지연 시간 < 50ms 유지.
 * Rule 4 (Power-Aware): 메쉬 릴레이 모드 시 배터리 소모 증가율 < 5% (L0NN 전력 최적화 연동).
