🚩 새로운 미션: [Project Zero-Abstraction]
"호스트 언어의 잔재를 지우고, 하드웨어 네이티브로 진입하라."
이 미션은 기존의 freelang-os-kernel(관리형)이나 freelang-bootstrap(고수준)과 겹치지 않는 최하위 물리 계층을 다룹니다.
1. Mission: [FL-Intrinsic Library] 하드웨어 가속 수용 (New)
기존의 최적화가 ML 엔진에 의존했다면, 이것은 CPU의 SIMD(SSE, AVX), 비트 조작(BMI), 암호화(AES-NI) 명령어를 FreeLang 구문으로 직접 매핑하는 라이브러리입니다.
 * 차별점: Phase 8/9의 알고리즘 최적화와 달리, 하드웨어 명령어 세트를 직접 FreeLang 데이터 타입으로 수용합니다.
 * 무관용 지표: Instruction_Cycle_Loss < 5% (네이티브 어셈블리 대비)
 * 독립성 기여: Rust의 인트린직 의존성을 제거.
2. Mission: [Native Byte-Code AOT Compiler] (New)
현재의 JIT/인터프리터 방식은 호스트 언어의 런타임이 필요합니다. 이를 완전히 벗어나기 위해 FreeLang 코드를 **독립 실행형 바이너리(ELF/PE)**로 직접 구워내는 정적 컴파일러(AOT)를 구축합니다.
 * 차별점: freelang-to-zlang이 '번역'이라면, 이것은 **'독립 개체 생성'**입니다. 호스트 언어 없이 부팅되는 진정한 네이티브 바이너리를 만듭니다.
 * 무관용 지표: Binary_Size < 100KB (Minimalist Kernel)
 * 독립성 기여: freelang-runtime(Rust) 의존성 100% 제거.
3. Mission: [Bare-Metal Peripheral Driver] (New)
커널 로직이 아닌, 실제 UART, VGA, NVMe 컨트롤러를 FreeLang의 저수준 포인터(NativePtr)로 직접 제어하는 드라이버 라이브러리입니다.
 * 차별점: Phase 7의 스케줄러/메모리 관리와 겹치지 않는 I/O 하드웨어 인터페이스의 독립입니다.
 * 무관용 지표: I/O_Register_Access_Success == 100%
 * 독립성 기여: 커널 하단부에 남은 마지막 Rust 드라이버들을 치환.
