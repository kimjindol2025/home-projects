  🔐 인증 방식 이해

  .netrc 파일 방식 (현재 사용)

  장점:
  - 🔒 안전함 (파일 권한 600)
  - ⚡ 빠름 (자동 인증)
  - 🛠️  설정 간단

  작동 원리:
  git push gogs master
      ↓
  GOGS 서버에 연결
      ↓
  ~/.netrc 파일에서 자동으로 인증정보 읽음
      ↓
  로그인: kim
  비밀번호: 929b266ef2e69d9dcdc4f1b6cbf3141a068258b3
      ↓
  푸시 완료! ✅

  🐛 문제 해결

  ❌ "Permission denied" 오류

  # 원인: .netrc 파일 권한이 너무 개방적
  # 해결:
  chmod 600 ~/.netrc

  # 확인
  ls -la ~/.netrc
  # -rw------- (600이어야 함)

  ❌ "fatal: Authentication failed"

  # 1. .netrc 파일 확인
  cat ~/.netrc

  # 2. 기본 형식 확인
  machine gogs.dclub.kr
  login kim
  password 929b266ef2e69d9dcdc4f1b6cbf3141a068258b3

  # 3. 저장소 URL 확인
  git remote -v

  # 4. 네트워크 연결 확인
  ping gogs.dclub.kr

  ❌ "fatal: no changes added to commit"

  # 커밋할 파일이 없음
  git status  # 변경사항 확인

  git add .   # 변경사항 추가
  git commit -m "메시지"

  💡 유용한 명령어

  푸시 전 확인

  # 커밋 로그 보기
  git log --oneline -5

  # 푸시될 커밋 확인
  git log origin/master..HEAD

  # 변경 내용 미리보기
  git diff HEAD~1

  강제 푸시 (주의!)

  # 로컬 커밋이 원격보다 뒤처있을 때
  git pull gogs master

  # 또는 강제 푸시 (위험! 신중히)
  git push gogs master --force

  여러 저장소에 한번에

  # 양쪽 모두 푸시
  git push gogs master && git push origin master

  # 실패하면 중단하고 알림
  git push gogs master && git push origin master &&
  echo "✅ 양쪽 푸시 완료"
