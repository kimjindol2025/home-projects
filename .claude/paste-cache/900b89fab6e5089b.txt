테스트 코드에서 **빠져나갈 수 없는 무한 루프**를 만들고 싶으신 거라면 아래처럼 작성하면 됩니다.

### 1. 완전 무한 루프 (절대 끝나지 않음)

```javascript
// 무한 루프 - 절대 빠져나갈 수 없음
while (true) {
  console.log("이 루프는 끝나지 않습니다...");
  // break; 주석 처리하면 진짜 무한
}
```

```javascript
// 또는 for (;;) 형태 (가장 전형적인 무한 루프)
for (;;) {
  console.log("무한 반복 중...");
}
```

### 2. Jest 테스트에서 무한 루프 만들기 (의도적으로 타임아웃 유발)

```ts
// src/infinite-loop.test.ts
describe('무한 루프 테스트 (의도적 타임아웃)', () => {
  it('절대 끝나지 않는 테스트', () => {
    while (true) {
      // 아무것도 안 해도 무한
      // setTimeout이나 await 넣어도 끝나지 않음
    }
    // 이 줄은 절대 실행되지 않음
    expect(true).toBe(true);
  }, 1000); // 1초 타임아웃 설정 (Jest 기본 5초지만 여기선 강제 짧게)
});
```

실행하면:
```
npm test -- src/infinite-loop.test.ts
```
→ 1초 후 타임아웃 에러 발생

### 3. 조건이 있지만 사실상 빠져나갈 수 없는 루프

```javascript
let i = 0;
while (i >= 0) {           // i는 절대 음수가 될 수 없음
  console.log("i =", i);
  i++;                     // 계속 증가
  // break 조건이 없거나 불가능한 조건
}
```

### 4. setInterval로 무한 반복 (테스트에서 자주 실수하는 패턴)

```ts
it('setInterval 무한 루프', () => {
  setInterval(() => {
    console.log("1초마다 출력...");
  }, 1000);

  // 테스트는 여기서 끝나지 않고 계속 대기
  // Jest가 timeout 날 때까지 실행됨
}, 5000);
```

### 요약: 가장 확실하게 "빠져나갈 수 없는" 코드 TOP 3

1. `while (true) {}`  
2. `for (;;) {}`  
3. `setInterval(() => {}, 1)` + 테스트 종료 안 함
