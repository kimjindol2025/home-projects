  ---
  추가된 것

  solver/fixpoint.fl — Tarski 고정점 반복
  LatticeVal: ⊥ < Unknown < Partial < Stable < ⊤
  transfer(): 각 IR 노드 종류별 전이 함수
              A1: state → 즉시 STABLE
              A2: consume → 입력 STABLE 후 STABLE
              A3: constraint → 타입 검사 후 STABLE
              A4: evolve → 단조 시간 후 STABLE
              A5: observe → 입력 STABLE이면 STABLE
  iterate_until_stable(): xₙ₊₁ = xₙ 도달까지 반복

  solver/propagator.fl — AC-3 변형 제약 전파
  Worklist BFS: 변경 노드 → 영향받는 이웃 자동 큐잉
  기존 DFS 재귀 대비: 불필요한 재계산 없음
  전파 로그: 디버깅용 변화 추적

  solver/scheduler.fl — 전략 선택기
  EAGER  → 전파 우선 (작은 그래프)
  LAZY   → 고정점 우선 (큰 그래프)
  HYBRID → 자동 선택 (기본값, node_threshold=50)
  A5 보장: 전략이 달라도 state_id는 항상 같음
