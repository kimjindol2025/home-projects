가장 먼저 웹 브라우저가 이해할 수 있는 파일 시스템 데이터를 뽑아내야 합니다.
핵심 로직 설계 (Draft)
# tree-renderer.fl

fn getWebTree(rootHash: string): map {
    let treeData = readObject(rootHash) # tree.fl 엔진 사용
    let result = []
    
    for entry in treeData {
        let node = {
            "name": entry.name,
            "type": entry.type, # 'blob' or 'tree'
            "hash": entry.hash
        }
        
        # 디렉토리인 경우 재귀적으로 탐색하여 하위 구조 포함
        if entry.type == "tree" {
            node["children"] = getWebTree(entry.hash)
        }
        
        result.append(node)
    }
    
    return result
}
