FreeLang 현재 능력 vs FAF 필요 기능 분석

  ┌─────────────────┬───────────┬─────────────────┐
  │    필요 기능    │   현재    │    구현 방향    │
  │                 │ FreeLang  │                 │
  ├─────────────────┼───────────┼─────────────────┤
  │ 변수, 함수,     │ ✅ 완전   │ 그대로 사용     │
  │ 조건문, 루프    │ 지원      │                 │
  ├─────────────────┼───────────┼─────────────────┤
  │ 문자열 처리     │ ✅ 기본   │ 그대로 사용     │
  │                 │ 지원      │                 │
  ├─────────────────┼───────────┼─────────────────┤
  │ HTTP 클라이언트 │           │ FreeLang        │
  │  (Claude API    │ ❌ 없음   │ stdlib로 구현   │
  │ 호출)           │           │ 필요            │
  ├─────────────────┼───────────┼─────────────────┤
  │ HTTP 서버       │           │ FreeLang        │
  │ (Gateway)       │ ❌ 없음   │ stdlib로 구현   │
  │                 │           │ 필요            │
  ├─────────────────┼───────────┼─────────────────┤
  │ JSON 파싱       │ ❌ 없음   │ FreeLang으로    │
  │                 │           │ 구현 필요       │
  ├─────────────────┼───────────┼─────────────────┤
  │ 파일 I/O        │ ❌/?      │ 확인 후 구현    │
  │                 │ 불명확    │                 │
  ├─────────────────┼───────────┼─────────────────┤
  │ 프로세스 실행   │ ❌ 없음   │ FreeLang으로    │
  │ (shell 명령)    │           │ 구현 필요       │
  └─────────────────┴───────────┴───────────
