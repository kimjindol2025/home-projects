## 📁 생성된 파일 (7개)

### v2.6.0-spec/ (2,000줄 - 공식 명세)

1. **grammar.fl** (600줄)
   - 완전한 파서 구현 (Lexer → Parser)
   - 6가지 기본 구문 타입 (declaration, function, expression, statement, type)
   - 30+ 파싱 함수 포함
   - 완전한 연산자 우선순위 체계

2. **semantics.fl** (600줄)
   - Hindley-Milner 타입 추론 엔진
   - 제약 전파 (Constraint Propagation)
   - 단일화 알고리즘 (Unification)
   - 트레이트 시스템 + 내장 트레이트

3. **stdlib_spec.fl** (400줄)
   - 10개 stdlib 모듈 명세
   - 50+ 함수 시그니처
   - Array, String, Dict, Math, IO, Iterator 등

4. **type_system.md** (400줄)
   - 완전한 타입 시스템 문서
   - 기본/복합/제네릭 타입
   - 타입 추론 알고리즘 상세 설명
   - 11개 섹션 (1,000+ 라인)

5. **LANGUAGE_SPEC.md** (100줄)
   - 공식 언어 명세
   - 14개 섹션 (어휘 → 예제)
