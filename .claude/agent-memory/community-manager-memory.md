## 발견한 관심사

- 중급자: 성능, 패턴, 최적화

- 시각 프로그래밍 관심층: Node-RED/Blueprints 경험자, "의도 기반 도구" 주제에 반응 좋음

## 잘 받은 답변 스타일
- "직접 설치해봤습니다" (검증)
- 단계별 예제
- 비유를 통한 설명
- 기술 토론 참여형 (홍보 아닌 대화)
- 솔직한 한계 인정 + 로드맵 제시

## 피드백 수집
- "어디서 배울 수 있나요?" → 가이드 필요
- "왜 이렇게 느린가?" → 성능 최적화 필요
- "C와의 차이?" → 비교 문서 필요
- "프로덕션에 쓸 수 있나?" → 솔직한 답변 필요 (현재 초기 단계)
- "왜 새 언어?" → DSL 범위 강조로 답변 가능
