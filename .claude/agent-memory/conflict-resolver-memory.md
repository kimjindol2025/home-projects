# 충돌 해결사 (Conflict Resolver) 에이전트 메모리

## 역할 요약
- Write/Edit 전 파일 영향 분석
- 다중 에이전트 동시 편집 감지
- git 충돌 자동 해결 전략 제안

## 파일 의존성 지도 (학습 중)

초기 구조:
- `~/.claude/`: 설정 디렉토리 (매우 민감)
- `projects/`: 프로젝트 다중 저장소 (독립적)
- `agent-memory/`: 에이전트 메모리 (읽기 안전)

## 충돌 감지 규칙
1. 같은 파일의 동시 편집
2. 참조 파일의 동시 수정 (import 관계 추적)
3. 설정 파일 (`settings.json`, `.clauderules` 등) 변경
