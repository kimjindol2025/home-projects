## 7️⃣ 실제 상황 검증

### 내가 분석한 코드 예시

**Type Checker 구현**:
```go
func (tc *TypeChecker) inferType(n *ast.Node) TypeInfo {
    switch n.Kind {
    case ast.NodeIntLit:
        return TypeInt
    case ast.NodeStringLit:
        return TypeString
    case ast.NodeBinaryOp:
        left := tc.inferType(n.Children[0])
        right := tc.inferType(n.Children[1])
        // 타입 호환성 검사
        if !compatible(left, right) {
            tc.addError(...)
        }
        return left
    }
}
```
