CORE FEATURES
================================================================================

✅ Memory Allocation (malloc)
   - O(1) performance
   - Array-based allocation table (1,000 max objects)
   - Track: address, size, ref_count, GC marking
   - Statistics: allocated size, number of objects

✅ Memory Deallocation (free)
   - O(n) performance (n = allocated objects)
   - Swap-to-delete strategy (O(1) removal)
   - Update statistics (freed size)
   - Handle invalid addresses gracefully

✅ Mark-and-Sweep Garbage Collection
   - Mark phase: Identify reachable objects
   - Sweep phase: Release unreachable objects
   - Trigger: When heap usage > 80%
   - Track GC execution count

✅ Memory Pool (Object Pool)
   - Pre-allocated fixed-size blocks
   - acquire() / release() interface
   - Reduce allocation overhead

✅ Leak Detection
   - Identify unreachable objects
   - Criteria: marked=false AND ref_count=0
   - Return leak count (perfect accuracy)
   - Calculate leaked memory size

✅ Allocation Statistics
   - Track total allocated bytes
   - Track total freed bytes
   - Track current heap usage
   - Track number of live objects
   - Track GC execution count
   - Calculate fragmentation ratio

================================================================================
ARCHITECTURE HIGHLIGHTS
================================================================================

Memory Layout (64KB):
  0x0000 ~ 0x5000:  Stack (20KB)
  0x5000 ~ 0xFE00:  Heap (44KB)  ← Dynamic allocation
  0xFE00 ~ 0xFFFF:  Globals (512B)

Allocation Table (Array-based):
  allocations[i]:   Block start address
  sizes[i]:         Block size
  marked[i]:        GC reachability flag
  ref_count[i]:     Reference counter

GC Algorithm (Mark-and-Sweep):
  1. Mark phase:   Mark all reachable objects
  2. Sweep phase:  Release unmarked objects
  3. Trigger:      When heap > 80% utilized

Design Decisions:
  ✅ Array-based vs Linked-list:  O(1) malloc wins
  ✅ Swap-to-delete:              No compaction overhead
  ✅ Reference counting + GC:     Handles all cases
  ✅ 80% threshold:               Early GC, 20% buffer
